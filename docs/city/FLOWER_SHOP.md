# 花店使用说明（city.2）

在河西街分类下建立花店主文字频道，然后在该频道执行：

```text
/城市 绑定 名称:花店 街道:河西街 类型:花店
```

如果以前绑定为普通店铺，请重新选择类型「花店」。线程继承主地点。

- `/城市 花店`：查看四款花束图片和价格，选择商品后打开私密确认订单。
- `/城市 花店 商品:玫瑰花束 数量:1 赠给:@朋友 赠言:生日快乐`：创建赠送订单，确认后扣款。
- 在花店真实@机器人，明确说「买一束玫瑰送给@朋友」：创建待确认订单；打开自己的订单后确认付款。
- `/城市 礼物`：在服务器任意频道查看花束库存，领取本人待收礼物。
- `/城市 营业 营业中:否` 或 `是`：有管理服务器权限的管理员在花店主频道开关营业。已购买礼物仍可领取。

玫瑰28、向日葵24、满天星18、混合38酒馆币；每次1至10束。钱包沿用原系统，重复按钮不会重复扣款或授予花束。待确认订单3分钟失效。

店主沈清禾使用独立人设和当前地点场景，回复有店主姓名；仍是同一Discord机器人应用。花店不读取红豆粉的关系分数，也不把酒馆对话当作花店现场。独立NPC好感档案尚未实现。

花束描述和NPC背景由Gemini起草、审查并批准后进入flower-copy.mjs。四张商品图通过ASSETS提供。真人Discord呈现与自然聊天效果需服务器成员实际试用。
