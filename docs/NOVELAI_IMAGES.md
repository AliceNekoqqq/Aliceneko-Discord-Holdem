# 红小豆 NovelAI 生图

## 当前开放状态

用户已确认开放，当前默认 `enabled:true`，可通过 @红小豆的自然语言请求或 `/ai 生图 绘制` 生图。开发者仍可用 `/ai 生图 默认 开放:false` 关闭。密钥仅在 Cloudflare 的 `NOVELAI_API_KEY` Secret 中；不进入模型提示词、队列或仓库。

## 使用

- 开放后可直接 @红小豆说“帮我画只猫”“想看看你今天的穿搭”。本轮聊天模型同时整理英文提示词与隐藏调用；后台只接受当前用户消息的意图证据。引用、假设、否定与旧记录不应触发。
- `/ai 生图 查看` 私密显示默认值、本人偏好和排队状态。
- `/ai 生图 额度` 向所有成员开放，私密显示红小豆共享账号的 NovelAI V5 剩余百分比、额外额度和预计再恢复 1% 的时间（若 NovelAI 提供）。查询只读取订阅状态。
- 可直接选择尺寸、步数、引导强度、采样器、数量、种子、前置正面、后置正面和负面提示词；高级参数仍可用JSON。
- `/ai 生图 偏好` 打开独立私密面板，按 Discord 用户账号跨服务器共用。基础数值弹窗填写宽、高、步数、CFG和张数；进阶弹窗填写种子、rescale；模型、采样器和调度使用下拉选择。
- 面板的“提示词模板”页可分别编辑前置正面、后置正面、负面提示，自动带入当前生效全文。数值留空表示跟随默认；提示词保存空白表示不用该段，点对应“跟随默认”可移除该栏个人覆盖。保存会返回面板展示当前值，不触发生图；非法输入不保存，其他用户不能操作本人面板。
- 面板的“恢复全部默认”需要确认，也可取消。修改个人设置不改变全局默认或已排队批次的参数。
- `/ai 生图 重置` 清除本人全部偏好，恢复跟随默认值。也可在模板弹窗清空并提交，以空段覆盖默认值。
- `/ai 生图 绘制 描述:... 参数:{...}` 可填写中文或英文；与聊天入口一样，先由当前文本模型理解要求并整理英文主体画面，再提交生图。`试画`也经过同样整理。
- `/ai 生图 默认 参数:{"steps":28,"scale":5}` 仅开发者可调，逐项合并。
- `/ai 生图 试画 描述:...` 仅开发者可用，允许在关闭期间试画，忽略开发者的个人偏好以核验全局默认值；本次参数仍可覆盖。
- `/ai 生图 默认 参数:{"enabled":true}` 开放；`false` 停止接受新请求，已受理批次仍按冻结参数完成。

对话中可直接说“我要一张猫咪图，1024*1024，24步，CFG 6”。和红包一样，由同一轮聊天大模型判断生图需求，整理英文画面提示词、单次参数及本轮逐字证据，作为隐藏JSON字段输出。程序不通过关键词或正则读取生图意图、尺寸和数字，也不补填模型漏掉的参数；只核验字段、范围、本轮证据和身份，然后合并本次参数、个人偏好与默认值。中文数字、口语表达、否定与后文改口由大模型理解。

斜杠绘制/试画先私密延迟确认，由现有生图 Durable Object 承接模型整理，避免普通 HTTP 后台任务30秒期限截断慢请求。同一指令ID持久去重（最近500条），不保存交互token；整理失败仅私密提示，不使用原始描述兜底生图、不自动重新执行整条指令。关闭状态、开发者权限及明确参数先核验。描述中的参数由模型附逐字证据提取；专用选项/高级JSON参数覆盖模型提取值。模型整理保留当前人设、身份与独立外貌/可选衣柜规则，不读取额外聊天历史。

优先级：指令选项/高级JSON > 本轮描述中明确提取的参数 > 个人偏好 > 全局默认。自然语言的一次参数需附本轮逐字证据，不会修改持久偏好或默认配置。红包/点单与花店独立 NPC 的轮次保持原处理路径，不触发生图。

## 个人外貌

- 每位成员可用 `/ai 生图 外貌` 保存自己的外貌提示词。填写 `提示词` 可直接保存或替换英文标签，留空可私密查看，单独选择 `清除` 可删除。外貌按服务器与 Discord 账号保存，最多 1600 字。
- 留空打开外貌面板后，点「AI 生成标签」。可以用中文或英文描述，每轮预览英文候选并继续调整。模型失败时可重试上一轮，原有草稿保留。点「确认保存」后候选才生效，放弃草稿时保留已保存的设定。
- @红小豆说“画我在雨里撑伞”“帮我画 @某成员”或“画我和 @某成员 的合照”。斜杠 `/ai 生图 绘制` 可用 `人物` 选择自己或其他成员。画某成员时使用那位成员自己的外貌。
- 生图时，Gemini 整理本轮要画谁与画面细节，保存的原文在加入 NovelAI 队列时才读取。V4、V4.5 和 V5 按人物加入各自的提示词；V3 合入共用主体描述。明确要求这次不用外貌设定时，可跳过该成员的设定。AI 标签助手会把草稿和最近问答单独交给文字模型，不写入聊天记忆或请求日志。

## 候选默认值

| 参数 | 默认 |
| --- | --- |
| model | nai-diffusion-4-5-full |
| width / height | 832 / 1216 |
| steps / scale | 28 / 5 |
| sampler / noise_schedule | k_euler_ancestral / karras |
| cfg_rescale | 0.15 |
| seed | -1（随机） |
| n_samples | 1 |
| 自动额外画质词 | 不追加 |
| prompt_prefix / prompt_suffix | 用户指定的固定正面 / 后置正面原文 |
| negative_prompt | 用户指定的1033字负面提示词原文 |

最终正面提示词严格按三段拼接：

`前置正面（prompt_prefix） + ", " + AI本次画面描述（image.prompt） + ", " + 后置正面（prompt_suffix）`

负面提示词独立传入 `negative_prompt` 和 `v4_negative_prompt`。默认三段原文见 `novelai-default-prompts.mjs`，保留用户的拼写、重复词、空格和权重。不会自动另加第四段画质词；旧 `quality` 设置只兼容读取，不再改变拼接。

个人偏好、单次参数和开发者默认使用相同三栏。未填某栏时逐层继承，填写后仅替换对应栏；使用高级参数的空字符串可清空该栏。AI只编写中间的主体画面，通常50–100个英文词，按主体、外貌、动作服装、场景、构图和光影排列；不复述固定画师串、年份、通用质量词或数值参数。只有用户明确更换某栏模板时才由模型提供该栏的单次覆盖。

`/ai 生图 查看 范围:默认参数 提示词:负面提示` 可私密查看任意一栏全文，避免长模板被Discord消息长度截断。默认配置迁移到三栏只执行一次，个人覆盖及已受理批次的冻结请求保持。

模型支持 V5 Full/Curated、V4.5 Full/Curated、V4 Full、V3。可在绘制时单次指定模型、在偏好中保存个人模型，也可以对红小豆明确说用 V5 或 V5 Curated。V5 使用流式接口，Discord 只接收最终 PNG。

宽高为64的倍数、各64–1536且单张不超过1048576像素；步数1–50，CFG 0–10，CFG rescale 0–1，seed为-1或0–4294967295整数，张数1–4。采样器支持 Euler、Euler a、DPM++ 2M/2S a/SDE；调度支持 karras/exponential/polyexponential/native。每栏提示词最多4000字。非法参数整次拒绝，不静默改值。

## 队列与失败

所有服务器共用专用 Durable Object `system-novelai-images-v1`，继续使用既有 PokerTable 类和 TABLES 绑定，无新增迁移。每批结束后至少等待35000ms才开始下一批；无并行生成。最多20批未完成，每人最多一批等待/生成。本次参数入队时冻结。

队列、冷却、处理租约及最近500个请求ID持久保存。生成前记录处理中，150秒恢复租约；恢复后只标为结果未知，不重发 NovelAI 请求。等待达到30分钟的请求过期。生图接口明确返回 HTTP 429 时，共用队列暂停至少65秒，并遵守更长的 Retry-After。有效期内原任务使用原参数、种子和请求 ID 自动再试一次，第二次429结束该批并提示何时可以重新发起。鉴权、额度、服务异常、超时、图片格式或 Discord 发送异常均不自动重新生图，避免重复消耗。Discord 使用来源ID nonce 去重。图片在内存中转成PNG附件上传Discord，不把编码图片写入配置或聊天正文。

`/health?commands=1&images=1` 仅返回配置存在状态、开放开关、模型、队列数量、常规35秒间隔与429重试次数上限，以及指令 schema 是否一致；另返回最近5批的结果状态、时间、失败阶段、HTTP状态和通知送达标记，不公开请求ID、频道ID、个人偏好、描述、图片或凭据。

网络请求通过包装函数调用，避免把Cloudflare原生fetch绑定到服务实例上引发Illegal invocation；生成、附件上传和失败通知共用此修复。失败日志只记录阶段和状态码，不记录请求头、密钥、提示词或图片。

## 验证边界

本地定向测试覆盖参数、个人隔离、默认试画、意图证据、隐藏字段、并发、35秒间隔、对象重建、处理租约、429 延迟重试上限、非429错误拒绝重试、附件投递及Worker路由。当前已按用户授权开放；未代替用户向真人频道发送测试图，真实 NovelAI 生成及 Discord 手机端效果由用户自然语言试画验收。


## 红小豆外貌与衣柜

`novelai-character-profile.mjs`保存独立生图外貌及可选衣柜资料，随生图指导交给同轮聊天模型。画红小豆时使用最新粉色卷双马尾、发饰和星形瞳孔等参考；不将这些词加入全局画风模板或其他人物的画面。用户本次明确改变细节时优先遵循本次要求。

“酒红水手服与白色针织开衫”是可选衣柜预设，包含项圈及服装配饰。不会因为画的是红小豆就自动穿上这套。用户明确点选或要求从衣柜选择时才使用；指定其他穿搭或只取其中一件时，不附带整套。例：“画红小豆穿蓝色晚礼服”与“画红小豆穿衣柜里的酒红水手服与白色针织开衫”。模型将选定外貌/服装整理到本次主体段，后台不做关键词识别或硬拼接。
