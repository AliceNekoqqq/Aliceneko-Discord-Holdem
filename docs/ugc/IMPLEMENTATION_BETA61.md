用户填写整数售价10～50币，单字段多轮候选修改和采用/放弃；取消、重新研发、回退完整问答均有60秒二次确认，绑定本人/服务器/会话/版本。确认入库原子写入菜品、定稿、每日名额和回执，清除临时正文；重复确认返回同一菜品。每人每服北京时间自然日最多成功一款。闲置30分钟/绝对2小时清理，失效生成租约可恢复。

模型每轮最多一次正常生成加一次JSON修复，不进行隐藏连续重试。按每轮预占2次调用预算，以保证最多40次调用/20轮的硬上限；取消/重研/回退不重置预算。每人每服每日最多3次新会话；该限制不等于成功研发名额。服务器已有设备由程序校验，价格和身份不由模型决定。
