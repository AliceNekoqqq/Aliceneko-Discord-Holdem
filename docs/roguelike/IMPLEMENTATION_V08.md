# 灯下迷城 v0.8 / beta.55 精修

用户要求将整体评估中能改的先改。本批实现遗物纠错、选牌分页、敌人阶段差异、职业特色、契约后效、平滑进阶与合并领奖，不再单纯堆牌数。

## 玩法

- 余烬小铲在本轮首次用盾挡伤时点燃敌人，不再错误地在打灼烧牌时加盾；旧伤仅进阶初始注入，不进入奖励/商店/事件牌池。信号弹为灼烧2＋标记1，避免与冷灰包3灼烧仅数值高低之别。
- 六Boss分别保留黑灯蓄焰、烛灰/反伤、多段映身、条件裁断/净化、三段钟鸣、巨钟震荡/反伤。九精英也各有阶段循环，阶段名和实时意图可见；当前回合不变，下轮切换，一次触发，濒死不救回。进阶及契约加成后的蓄力预告与下轮实际伤害一致。
- 八职业各4通用＋4特色牌：重复药包分为旅人治疗＋标记、守门治疗＋盾/反击、调酒治疗＋净化、信使治疗＋抽牌、钟匠治疗＋备势、医师高治疗/净化、驯兽治疗＋召唤、铸器治疗＋锻造。信使增加抽牌和择弃防守；共享牌池与桥梁奖励保持，有限治疗不可回声。
- 15种事件。其中余烬借据领12余烬但未来2战每段敌攻＋1；封印遗物付4HP领取事先展示的一件未拥有遗物，之后营地基础治疗－2，至多叠两次；Boss交易付12余烬令本幕Boss初始最大生命－15%。免费离开、明确确认、服务端验证成本与候选，history/debtBattles/campPenalty/weakenedBossActs保存在JSON存档；无酒馆币交易。

## 难度和操作

0～10阶不跳过职业解锁。末阶原本突然的生命40%提升逐步分摊：全敌系数1/1/1.04/1.08/1.12/1.16/1.20/1.24/1.28/1.34/1.40；攻击累计加成0/0/0/1/1/1/2/2/2/3/4。Boss额外生命从4阶逐步增加，8阶达25%。营地、价格、最大生命、精英开场盾、Boss阶段加成、伤牌、提前转阶段门槛保持。设置页显示新规则；旧规则版本单独冻结。

升级/删牌选牌页面每页25张，商店两项服务分开；营地及事件也可翻页，所有UID均可访问。翻页只读，具体动作重新验证本人、房间、请求版本、候选及费用。刷新/详情可用旧按钮读最新状态；旧操作不能修改当前局。

战利品预选当前三候选中按基础效果/已有标签评估的推荐牌、首个未拥有遗物与空槽道具。摘要列明所有选择，可换选、分别跳过、跳过全部或一次确认。满槽道具默认不选，必须明确替换位置。REWARD_SELECT仅保存选择，REWARD_CLAIM一次把所有候选与实体变化提交后推进站点；失败原快照不变、重复请求不重复加牌。默认普通战领奖2步→1步，精英/危险战3步→1步；没有自动替玩家打牌。

## 验证与兼容

发布范围225/225通过，含遗物实际触发、15阶段实际切换/恢复、蓄力加成、UID分页、非法来源/旧按钮、契约代价与后效、合并领奖、库存替换、版本分派和原有结算幂等/隔离。

160次无生命注入真实动作模拟，八职业×4种子×5难度：0/3/6/8/10阶通关分别29/27/23/22/13（每级32样本）；八职业初阶均有完整15站通关。每步经JSON恢复，固定策略及推荐奖励；样本小、策略有限，不能代表真人胜率。高阶若干职业样本仍无通关，继续按真人构筑反馈调平衡。程序未量化Discord网络等待/真人阅读和确认耗时。
