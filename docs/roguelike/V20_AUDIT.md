# beta.89 / 灯下迷城 v0.20

本版增加有限敌人战术压力，改善职业资源衔接。牌数124、每职业6张专属、敌人数30、路线与营地保持；v0.19及更早引擎/目录继续派发原规则。

## 调整

- 灰烬守卫、空瓶投手、镜翅蛾、铆钉搬运工、钟尘守望者、锈页书记的一个纯架盾意图改为小额攻击后架盾，护盾数值沿用原值。其余轮次/生命/护甲保持，不给所有普通敌人统一加伤。
- 全部9精英第7轮起每段攻击+1；全部6首领第7轮起+1，第11轮起+2。压力到上限后不再增长，无回合数失败限制。普通敌人不附加此压力。仅攻击/蓄力攻击及条件/节奏攻击分支受影响，护盾、灼烧和反伤不增加。
- 文字和图片提前显示压力开始轮次与当前值；实际意图包含对应轮次的增压。蓄力预告计算下一轮真实意图，阶段开场预告也按真实轮次计算；破势减伤只应用一次。
- 热铁先获得锻值，再结算武器伤害；当前锻值至少4时穿甲，不消耗锻值。升级仍保留原伤害差值，公共锻造组件不受职业限制。
- 渡鸦医牌每轮首次主动实际治疗除原2盾外再获得1备势；满血、道具、不产生实际治疗或本轮重复治疗不触发。治疗量保持，营地恢复仍重要。
- 退件重投回收的真实弃牌本轮减1费，最低0；不复制、不复活消耗牌、不回收本牌。改费随轮次结束清除；攻击和回收仍占行动，维持3/4行动上限。
- 版本路由、私密界面、升级预览、知识条目、每日挑战与旧局观察/结算统一支持v20。现有菜品研发恢复及UGC图片保留。
