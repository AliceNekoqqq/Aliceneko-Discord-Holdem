## 2. 职业与远期角色

沿用主案六职业：提灯旅人、守门人、烬火调酒师、镜巷信使、钟楼匠、渡鸦医师。起手不同，基础属性先一致；特色遗物占原开局赐福预算，不额外叠送被动。特色起始牌可进入相应主题池供其他职业获得，不能被实现成职业锁牌。

再规划两个远期职业：

- **巡兽师**：一只灯灵伙伴，有生命、挡伤、攻击、牺牲与复原选择。命令与额外收益需要明确成本；先冻结伤害承受顺序，再实现。酒馆已有宠物永久等级不提供竞技属性。
- **铸器匠**：战斗内锻造一件武器。锻造牌兼带少量防护，武器牌兑现强化；强化不跨战、有上限。比较“先锻造”与“现在攻击”的实际损血，不做永久购买最强武器。

烬火调酒师还可研究小容量“调剂”副资源，连接火力、护盾与生命代价；这是远期候选，不临时替换主案的预备/标记或新增第九条正式流派。

## 3. 十二条具体混搭连接

主案八流派保持：直伤破甲、防守反击、灼烧、回声延迟、自伤消耗、预备爆发、标记追猎、筛牌消耗。

| 混搭 | 连接方式 | 保留的代价 |
|---|---|---|
| 盾＋火 | 炭幕兼顾盾与烧，熏灯罩把格挡转为少量烧 | 敌先行动，施烧当轮仍要生存 |
| 盾＋直伤 | 盾转伤候选牌：先防守，再消费部分盾攻击 | 花掉盾就失去防护；需新规则 |
| 血＋火 | 燃血灯盏用生命换直伤/烧层 | 自伤先付，盾不抵生命代价 |
| 耗＋盾 | 封口药匣：主动消耗牌补一次有限盾 | 自然弃牌不触发，重放快照不再消耗实体 |
| 耗＋筛牌 | 消耗不需要的牌，筛牌找可重复使用的输出 | 消耗过多会缺牌，不能用掉全部输出 |
| 响＋直伤 | 一次合规回声重复关键攻击 | 不再触发首次主动攻击增益、不排新回声 |
| 响＋火 | 下一轮重放施火牌 | 不触发主动施烧加层；专门遗物另设有限钩子 |
| 响＋盾 | 下一轮自动重放盾牌，把主动位用于推进 | 抽牌前重放，不能看完手牌撤销 |
| 预备＋破甲 | 带盾预备铺垫，再由穿甲攻击兑现 | 预备一次消费、有时限；穿甲不穿盾 |
| 标记＋直伤 | 标记后由下一张攻击首包兑现 | 被盾挡住也消费，不把每包都加成 |
| 标记＋回声 | 上轮设标记，下轮回声兑现 | 注意时限，同一标记只有一次收益 |
| 筛牌＋预备 | 整理手牌，找能兑现预备的攻击 | 筛牌也占一次出牌，不能一轮做三步 |

可发展“炉边守夜”“沉钟猎手”“最后的处方”等组合。核心牌独立有效，一张普通桥梁即可起步，稀有遗物负责放大；不要求凑五件套。

回声自伤第二次照付；治疗不复制；消耗牌逐牌声明能否回声，现有可回声消耗牌仍按快照重放。标记、预备时限、叠加次序与回声来源上限全部按主案，不另开另一套规范。

## 4. 奖励、敌人、遗物的扩充重点

主案32新牌是候选预算，重复功能先合并。炭幕与烬火护幕、已有穿甲与裂甲刺、两张同功能预备盾牌不能为了凑数量全部入池。

九站短局要让连接器尽早出现。优先每流派有独立有效的发动牌、普通桥梁牌、兑现牌。可用“小主题包＋公共池”与主案的相关池/连接池/通用池做投放对照，开局冻结配置，刷新不重抽；不是现在修改奖励算法。

敌人沿用附案18候选，按构筑考题分组：蓄力大击、多段、护甲与盾、有限反伤、有限削层、公开阶段/条件意图。每种至少两种应对，不能暗中按玩家流派换成最克制招式，不能永久免疫整套构筑。反伤、治疗、净化、动态护甲与复合行动都需真正的新规则及存档，换文案不等于实现。

遗物按六类组织：基础、发动、桥梁、终结、契约、探索。现有连接遗物为主；远期可少量加明确代价的契约和改变信息/余烬效率的探索遗物。自伤代价在牌效果前支付，支付致死停止；探索不提高酒馆币收益或有奖资格。

## 5. 道具与榜单边界

保持主案：**2槽，每场战斗总共最多使用1件，不占两张主动卡额度，使用后该实体消耗。** 不改成每种各一次，也不混入“每轮1件、占主动次数”的另一方案。额外救急收益必须纳入供给/敌强验证，次数有限不是已经平衡的证据。

近期六件：止血布、碎镜片、冷灰包、折叠盾、鸦眼滴剂、退火盐，数值以附案为待测原型。物品不触发出牌、回声、标记或消耗遗物链。满槽时允许替换/放弃，删除旧物与领取新物原子保存；纯治疗满血、无状态净化禁用。道具局内获取，不兑换永久钱包。

同题固定职业、起手、规则/内容版本、候选供给；玩家的选路、赐福与奖励决策写入本局，不因选择不同拆榜。旧v0.4日赛保持相同候选自行选遗物；若新职业改固定起始遗物，明确属于新配置，不静默改旧局。

## 6. 实施顺序

先接通已有v0.4的Worker/酒馆入口、私密更新、恢复与结算，取得手机实测。再按主案首批3职业/4方向筛12张有差异的牌，加入少量连接遗物和已有机制敌人。之后开发跨轮、标记、筛牌/保留与另外三职业；道具库存/次数/存档同批验证。召唤、铸器、多敌另开版本。

数值比较覆盖不同牌序、无关键遗物、单流派与混搭、三幕资源、12轮失灯和实际点击。参考尖塔2提供设计依据，不能代替本作演算与真人体验。当前0/8/18/30收益、每日资格、60子限额与150总限额保持，设施价格另行标定。
