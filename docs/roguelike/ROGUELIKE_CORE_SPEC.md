# 灯下迷城 · 公共规则 v0.4

日期：2026-10-10（Asia/Shanghai），规则标识 lantern-rules-v0.4。本版已有三幕可执行JS模块、SQLite服务和Discord面板，尚未接到线上Worker。内容目录保持v0.3。尖塔2资料仅为机制参考；最终数值依据本游戏的手牌、能量、短局成长及手机操作验证。

## 1. 范围与版本

全局骨架3幕，每幕2个二选一房间和1个固定Boss，9个已选地图站。三幕内容已定义，合计20种牌、12件遗物、12种敌人；可在Python参考模型与JS规则模块演算整局，正式Bot尚未连接该入口。角色提灯旅人最大HP30，不自动在战斗/章节补满。局内余烬不带出、不兑换酒馆币；开局免费，不押钱包。

v0.2将v0.1抽3选1改为抽4/2能量/最多主动打2张，8实体基础牌；篝火改治疗/升级，开局和下一幕起始有赐福，Boss后先检查点。旧v0.1文档/27→30→23算例保留为对照，不是新版结果。规则与内容版本固定在开局，旧局不能静默换规则。v0.3保持第一幕原值，新增后两幕、多段攻击、商店与修灯事件。当前无线上肉鸽局需迁移。

当前现有经济150每日总额包含手动到店礼20、合格多人游戏与伙伴，伙伴20子限额，欢迎60一次性；现有规则保持；肉鸽收益累计0/8/18/30、每日2次有奖开局、结算日60子上限已定，仍包含在150内。评分与日期策略见ECONOMY_AND_RANKING_V04.md。本批的初始牌值、敌强、余烬均是原型参数。

## 2. 阶段与站点

HOME负责找到/创建一局，不存为进行中阶段。进行中同服务器/同用户最多一局，可同服跨频道恢复，归属服务器固定；另服不能操作或领该局。RESULT不占进行中名额，即使待结算也可开新局，但记录独立保存。

| 阶段 | 合法动作 | 去向 |
|---|---|---|
| ROOM·赐福 | 固定三遗物选一或跳过 | 本幕ROUTE槽1 |
| ROUTE | 固定候选二选一，不可重选未走支路 | ROOM或BATTLE |
| ROOM·篝火 | 治疗或选择未升级实体升级，二选一 | 下一站 |
| ROOM·其他 | 明示资源代价的房间动作；商店可多次买或离开 | REWARD或下一站 |
| BATTLE | 逐张打牌、主动结束回合、看详情 | 本战或奖励/终局 |
| REWARD | 按队列选择/跳过当前奖励 | 下一项奖励或下一站 |
| CHECKPOINT | 前两幕Boss后继续/确认撤离 | 下一幕ROOM·赐福或RESULT |
| RESULT | 看固定结果、实际到账、重试结算/新局 | HOME或新runId |

开始先ROOM·赐福，不占站。第一幕槽1两普通教学敌，槽2篝火/精英，第三站Boss固定且自动进入；每个分岔只选一个房间。首次打完Boss时必须有3个完成站，开局赐福/奖励选择不计站。

胜利先登记战斗完成事实及一次性余烬，再处理固定奖励队列；最后一个奖励处理完才递增完成站。普通战卡牌3选1/可跳过；精英先卡再遗物；第一幕Boss无遗物三选一，完成该站→检查点。继续才进入下一幕赐福，撤离不能预领；第三幕Boss直接通关，无第4幕/无用遗物。

路线、敌人、价格、奖励候选在首次到该阶段时持久化，刷新/恢复不重抽。任何奖励/房间完成仅一次推进。所有分岔保证可达无费用推进，商店买不起可离开；删牌最低4实体，消耗牌仍是永久牌组实体而非被永久删除。

## 3. 牌组与能量

当前整局唯一数值源为 RUN_CATALOG_V03.json，第一幕内容由 FIRST_ACT_CATALOG.json 原样并入；ACT2_CONTENT.json / ACT3_CONTENT.json 是后两幕来源，不可各自改成不同数值。初始牌组8实体：斩击×3（1费6伤）、格挡×2（1费5盾）、突刺（1费无视护甲4伤）、抢攻（1费先自伤2再9伤）、包扎（1费治疗4，本战消耗、不可回声）。实体ID唯一，升级只改选中实体，一局每实体最多升级一次；不能把同名3张一起升级。

每轮能量重置2，不跨轮存；抽4不同实体，主动次数0，最多主动打2张。初批无0费、回能、额外抽牌、额外回合。卡牌费用为1/2，不足能量不可打；纯治疗牌满血不可打；含有效护盾等其他效果的复合治疗牌满血可打，治疗部分仅恢复缺失HP。治疗牌本战消耗且不可回声。

每战当前牌组独立洗牌；draw/hand/discard/exhaust互斥。抽不足4时先取余牌，再洗此前弃牌补；不把已抽本轮实体重复补入。若总可抽实体不足4则少抽，不能复制/从消耗堆补牌。打出的普通牌立即入弃牌，消耗牌入本战exhaust；回合结束剩余手牌入弃牌，不触发打出。战斗结束全部消耗牌归回永久牌组，下战可再使用，升级保留。

单次成功出牌保存牌堆、能量、次数、HP、状态及版本，才允许下一张。第一张致死/击杀立即结束，不能先扣未执行第二张的能量或生命代价。2张已用自动结束；否则玩家可主动结束；无手牌或无合法出牌自动结束。暂离不替玩家自动决定。

## 4. 回合顺序

1. 轮开始清玩家临时盾、清过期状态；轮数+1、能量2、主动次数0、本轮触发标记归零，锁定敌意图且只预告。
2. 执行上轮排队回声，照付生命代价但不付能量/主动次数。胜败即停止；无回声或双方存活则抽手牌，保存可操作状态。
3. 逐张选择，先扣该张能量与主动次数，支付全部自伤代价；HP归零立即失败，卡其余效果不执行。
4. 按该牌effects顺序执行伤害/盾/灼烧/治疗；每个效果与触发后立即检查终止，不让后续效果救活或死后行动。主动出牌触发遗物按目录固定顺序，取得顺序只用于同优先级；重新恢复不改变顺序。
5. 玩家结束轮且战斗未结束时，清敌方上一轮架盾的剩余盾，再执行敌意图。attack的hits默认1，第二/三幕可为2或3，value是每段伤害，逐段消耗盾、扣HP、检查死亡及反击。charge当前不造成伤害，其value/hits仅预告下一轮攻击；必须显示“每段×次数”和总伤，不能把总伤再乘次数。
6. 双方仍存活，回合末先玩家灼烧、再敌灼烧：扣当前层数后减少1层，每次立即检查终止。新施加灼烧本轮末即扣，所以敌仍可能先行动。
7. 玩家临时盾清零；敌guard盾保留至玩家下一轮，然后在敌自身下次行动前清零。已满12轮仍未分胜败则失灯失败，不抽第13轮。

每个普通伤害包先护甲减伤（最低0）、再盾吸收、最后扣HP；突刺跳过护甲但盾照挡。自伤为生命代价、灼烧为独立HP损失，都绕过护甲/盾，不触发受攻击反击。玩家本批护甲0；护盾上限30，灼烧层数上限20。

胜利立即停止所有未到的敌行动、反击/回合末扣血；失败停止后续治疗/敌灼烧，不能转胜。同一个效果若未来确实双方同时归零，玩家失败优先。每次伤害先检查玩家再敌人；触发反击需要受击后玩家仍活着。

## 5. 遗物与有限触发

本版“攻击牌”指含直接damage效果的牌，“护盾牌”指含block效果的牌；纯burn牌是状态牌，不触发攻击遗物。复合牌可以同时符合两类，定义由效果推导，无未声明职业标签。

起始遗物固定三选一：余温火绒（每战首次主动攻击造成直接HP伤害后敌灼烧2）、门廊扣（每轮首次主动护盾牌额外盾1）、旧巡夜徽章（每战首次主动攻击牌直接伤害+3）。候选可跳过，不重复获得同ID。徽章在打出该攻击牌时消耗本战触发，即使被盾全挡仍消耗；火绒只有直接HP伤害>0才触发。多效果牌攻击增伤只作用第一个直接伤害包，护盾额外值只加第一个护盾效果。

精英遗物三类：主动施加灼烧增加固定层数；敌攻击被盾吸收后反击；首张可回声主动牌下轮额外重放。具体值见目录。每件反击遗物在每个被盾吸收的攻击段最多触发一次，未吸收的段不触发；不同ID可各自触发，逐个伤害包减敌护甲。反击本身不触发反伤链，玩家已死亡不触发；反击击杀立即取消剩余触发和剩余攻击段。

回声保存当时牌定义/升级快照，不依赖下轮再抽同实体；不移牌/不花能量/不计主动次数，照付其生命代价。本批治疗牌不可回声。重放不触发火绒/门廊扣/徽章/灼烧加层等主动牌触发，不再排回声；其他被动受击反击仍有效。战斗结束清待发生回声，不能带到下一房。

护盾/烧层截上限、单次升级/一次治疗消耗/有限遗物次数均服务于可解释短局，不能当作所有组合已平衡的证据。升级与战后奖励应改变整局决策而非永久数值碾压竞技。

## 6. 房间与资源

三幕普通战余烬8/10/12、精英14/18/22、Boss20/24/28；局内余烬与真实钱包隔离。篝火治疗 floor(maxHP×0.30)，最大30时9，或升级一个实体；满血治疗禁用，无未升级实体则升级禁用，必要时可直接离开。

路线见 FULL_RUN_FLOW.md：第一幕普通战二选一→篝火/精英→Boss；第二幕普通战/商店→篝火/精英→Boss；第三幕普通战/修灯事件→篝火/精英→最终Boss。后两幕普通支路具体敌人在ROUTE生成时固定。章节赐福各三件候选，不占站、无自动回血。

卡牌奖励为当前与此前幕解锁池3选1/可跳过，第一幕9种、第二幕12种、第三幕15种奖励牌；基础5种不直接加入普通奖励池。精英遗物池排除已拥有ID，不足3展示实际数，空池无奖励自动完成该队列项。新牌和遗物都不倒灌第一幕。

第二幕商店固定2张不同奖励牌，1费10/2费14余烬、各1份；单实体升级12（本房一次），删除8（本房一次且删后至少4实体）。可多次消费，消费留ROOM，免费离店才完成站。第三幕修灯事件三选一：支付12恢复6HP、支付10从固定三张本幕牌选一、免费穿过。满血修灯禁用；购牌在付款前预览，确认时选择与扣款原子完成，取消或跳过不付款，不能付款后反复换牌。事件成功动作即完成站，不重复收费或奖励。

价格/库存/候选/服务次数持久化，买不起不锁进度，不刷新、不回购、不按消费额奖励排行。进入新战清护盾、烧层、战斗触发/回声；HP、永久牌组/实体升级、遗物、余烬跨房保留。余烬无终局兑换或囤积奖金，酒馆币收益按v0.4终局契约结算，不兑换余烬。

## 7. 终局、榜单与持久化

CLEAR=最终Boss胜；RETREAT=前两CHECKPOINT本人确认；DEFEAT=HP0或12轮失灯；ABANDON=任意可操作阶段本人二次确认，不发币；EXPIRED=72小时无有效游戏动作，不发币。进入下一幕不自动回血。查看/刷新不延长期限，选路/出牌/有效结束回合/奖励/房间/继续章节等成功动作才重置。无持续轮询。

终局先固定不可再战的结果、完成站和唯一runId结算凭据，再准备入账。失败留RESULT待重试；旧待结算可与新局并存，用独立runId隔离，不能把新局余额写入旧流水。终局/操作凭据先持久化，入账事务失败保留RESULT待重试并可开新局；入账时钱包/日桶/流水/回执/付款快照一次事务完成。钱包与排行榜分别幂等，排名outbox独立更新，排名失败不回滚已到账的钱。每日已有总限额覆盖肉鸽；消费不恢复限额，不重复欢迎金，副本余烬不兑换。有奖名额使用开局北京日，收入使用首次成功入账北京日，榜题属于开局日。通关30/第二幕后18/第一幕后8；每天2有奖开局、结算日肉鸽60且含现有150。0币亦写唯一回执，不次日补领；客户端now无权决定日期。

普通局随机；每日挑战同北京日/服务器赛事/规则版本/初始配置/种子组，永久外观不加属性。允许不限练习次数取最佳。积分=完成Boss×1000+完成站×50+精英胜利×40+存活终局HP（仅CLEAR/RETREAT、至多30）；放弃/过期不上榜。不按点击速度/余烬/消费计分，完全同分并列；重复同题是练习机制，不把种子当秘密。地图/战斗/奖励随机子流独立，刷新只读保存值；榜组严格同版本同题，活动局按开局版本持续。

存档至少保存：runId/owner/originGuild/mode/version/seedGroup/startDay、阶段/幕/槽/完成站、HP/牌组实体升级/遗物/余烬、战斗draw/hand/discard/exhaust/轮数/能量/主动次数/意图/状态/每战每轮触发/回声快照、奖励队列及当前游标/固定候选、操作版本/最后有效时间、终局记录/结算凭据/到账/榜单待发送。每个有效动作原子更新资源/阶段/版本，重复返回现状，非本人/跨服/过时按钮拒绝。规则内容保留至所有引用该版活动局终结，历史结果仍可按原版本展示。

## 8. 本阶段验收边界

当前20牌/12遗物/12敌人目录、路线/奖励/检查点、商店及修灯事件与可执行模块一致；历史v0.3规则归档。JS战斗、状态机、经济、SQL服务、私密面板/解析、dispatcher和跨模块50项定向检查通过；SQL使用真实node:sqlite内存数据库加DO同接口适配器，非Cloudflare生产数据库。

JS随机采用独立作用域hash+xorshift并保存状态，与历史Python序列不同。8个JS种子按真实战斗/房间动作跑到终局，每次与JSON恢复后结果相同，至少有完整9站通关；不是人类胜率或平衡统计。旧Python648样本/19项检查仅作历史内容证据，不重跑、不挪作生产验证。

尚未接入现有Worker/大厅/命令/实际webhook、实机图面和真人经济。模块源码、SQLite测试通过不能称Bot已上线或实际可领币。生产连接需继续按IMPLEMENTATION_V04.md完成，并保留beta.52设备/ASSETS、聊天与每服务器伙伴。
