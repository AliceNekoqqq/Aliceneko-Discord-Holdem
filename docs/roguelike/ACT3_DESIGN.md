# 第三幕：无灯钟楼

第三幕把旅人带进停摆的钟楼：钟声不再报时，只把每次犹豫都变成一次可见的蓄势。场景由覆灰校时厅、断梁锤廊一路升至没有灯火的钟室；压迫感来自逐段逼近的攻击与短暂守势，不引入新状态或特殊结算。敌人血量、护甲、招式值和牌/遗物数值以 `ACT3_CONTENT.json` 为唯一来源。

## 敌人与战斗取舍

钟尘守望者以双铃连击测试护盾能否逐段承伤；罩住钟面时适合趁隙抢攻。灰尘校时师先拉紧发条，清楚预告下轮两段攻击，玩家可用格挡或在它退入钟影前压低血量。铸钟监工的双锤重击段数少但每段更重，架锤时会留下进攻窗口。无灯钟主用三声空钟预告三段伤害，再以钟壳闭合争取时间；面对多段攻击，护盾逐段消耗，反击也逐段判定，若反击击杀便取消剩余段。`charge.value` 表示下一轮每段伤害，配合 `hits` 预告总伤与段数；执行攻击按每段伤害结算。

## 新牌与章节遗物

敲钟弧斩用1费打出小额伤害并获得护盾，升级同时提高攻防；钟锤架势是2费消耗、不可回声的紧急补给，提供厚盾并治疗3点（升级为15盾/4治疗）。它含有效护盾效果，因此满血也可打出，治疗只恢复缺失生命；末响余火保留为2费消耗牌，以伤害加灼烧换取一轮集中投入。三张均可升级，只用既有伤害、护盾、治疗与灼烧效果。

余烬钟舌复用 `burn_bonus`，扩大主动灼烧；断铃镜片复用 `reflect`，多段攻击中每个被护盾吸收的命中都可能反击；终班徽记复用 `first_attack_damage`，加重每战首张主动攻击牌的首个伤害包。章节候选沿用既有遗物接口，不新增触发类型或回声遗物。

## 终局边界

无灯钟主倒下即第三幕Boss胜利并进入 `CLEAR`；不再生成第4幕、检查点或无用升级奖励。三幕总计九个完成站，进入新章不免费补满生命；路线收益需在有限HP与可用牌间权衡。本幕参数已纳入648条整局策略样本，复核见FULL_RUN_BALANCE_V03.md；仍需极端组合与真人手机体验验证，不声称最终平衡或上线。
