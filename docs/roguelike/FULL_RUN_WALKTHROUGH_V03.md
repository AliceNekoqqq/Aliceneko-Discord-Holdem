## 同种子冒险失败

同样初始遗物/策略，第二站改打精英：第一幕Boss后22HP/42余烬，第二幕普通战后18HP，精英后7HP，第二幕Boss后2HP/94余烬。确认继续没有免费补满；第三幕普通战后4HP/106余烬，再打铸钟监工，第4轮生命归零。已完成7站，余烬冻结106，未完成的精英不计第8站、不发22余烬，后续Boss/奖励不生成。

该局共31战斗轮、55主动牌、1次主动提前结束，动作代理量74；没有酒馆币收益。检查点本可撤离，第三幕也可改走修灯与篝火，但程序样例只演算一路冒险，未执行真实撤离服务。这个失败说明需要看当前HP与构筑选路，不能把同题种子理解为只要选更多精英就更好。
