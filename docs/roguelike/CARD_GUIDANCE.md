# 灯下迷城 · 手牌阅读与故事入口（beta.57）

实时地图与简单战斗图沿用beta.56。本批改善阅读，不修改v0.8战斗、构筑、奖励、存档或通关条件。

- 牌的效果按攻击、守御、恢复、火种、召唤、铸器、技巧显示类别与颜色；混合牌有多个类别。颜色只用于阅读，效果文字仍是主要依据。
- 图、文字、选项使用同一实体牌#编号；同名牌互相独立。当前费用/效果解析强化覆盖，强化标记不随可用状态消失。
- 自损与消耗单独标出。自损直接支付生命，当前生命不足会明确提示倒下；消耗仅指本战不再抽到。
- 不可用原因覆盖出牌次数、能量、纯治疗满血、伙伴缺失、纯目标牌没有另一张手牌。最终合法牌仍由战斗引擎决定。
- 当前手牌与意图生成短提示：剩余次数、防御、备势/标记、锻造、伙伴、目标或自损。条件敌人分支按本轮首张是否包含直接伤害效果判定，界面不再暗示任意攻击都会改变分支。
- 首页「玩法指南」「世界与角色」；职业设置「角色故事」；局内「玩法与故事」。均为本人私密只读面板，可以返回当前远征。
- 世界框架：红豆粉小酒馆流行的盒装桌游，盒内旧街、镜巷、无灯钟楼陷入长夜，单职业棋子越过三幕守关者、找回黎明。八职业各有来历、动机和招牌打法，全文见WORLD_STORY.md。真实玩家与领养伙伴不是盒内角色。
- bot知识库同步相同故事，不改变真实NPC人设；程序界面与知识文档使用同一文案来源。

代码：rogue-card-guide.mjs（共用阅读逻辑）、rogue-lore.mjs（共用故事）、rogue-ui/interactions/image.mjs（显示与路由）、bot-knowledge.mjs。
