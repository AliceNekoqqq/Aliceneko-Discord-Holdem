# 《灯下迷城》v0.2 第一幕战斗内容

本文件解释 [`FIRST_ACT_CATALOG.json`](FIRST_ACT_CATALOG.json) 中的牌值与敌人循环；JSON 是唯一数值来源。内容按共享契约设计，已完成参考模型交叉复核，结果见 BALANCE_REVIEW_V02.md；这不代表生产引擎或真人平衡通过。

## 牌组与升级

初始牌组为固定8张：斩击×3、格挡×2、突刺×1、抢攻×1、包扎×1。5种起始牌与9种奖励牌合计14种；引火属于奖励池。奖励牌覆盖多种选择：直接攻击（烬刃、重斩、蓄势突刺）、攻防结合（炭幕）、纯防守（迎击架势、灰墙）、灼烧（余烬爆发、引火）和消耗治疗（战地包扎）。没有零费牌；治疗牌消耗且不可回声。

升级效果逐张写在 JSON 的 `upgrade` 中。斩击、突刺、抢攻、奖励攻击牌提高伤害；突刺与蓄势突刺绕过护甲，重斩以2费换取更高单次伤害；格挡、迎击架势、灰墙提升护盾；引火、烬刃、炭幕和余烬爆发增强灼烧；包扎与战地包扎提高一次性治疗。抢攻升级同时把生命代价从2降至1，仍保留代价与回声重放时照付的风险。每张实体牌最多升级一次。

## 起始遗物与精英遗物

三件起始候选固定为余温火绒、门廊扣、旧巡夜徽章，符合每战/每轮标记范围。余温火绒要求主动攻击先造成直接生命伤害才施加灼烧；旧巡夜徽章加到首次主动攻击牌的直接伤害；门廊扣强化每轮首次主动护盾牌。精英奖励候选为炽芯（主动灼烧+1）、镜面护符（被盾吸收的敌攻击触发一次反击）、回声铃（首次可重放主动牌在下轮免费重放）。候选均可跳过，同ID不叠加；回声不复制治疗且不触发契约列出的主动遗物触发。

## 敌人与节奏预期

灯鼠（22 HP）以4伤扑咬、3盾防守、5伤扑咬循环，适合展示攻击与敌方护盾清除时点。灰烬守卫（24 HP）先举4盾，再以5伤盾击和4伤短斩循环，迫使玩家判断破盾还是先防守。两者分别落在普通敌人的20–24 HP与4–5攻击目标区间。

余烬骑士（28 HP、护甲3）循环为蓄力预告、8伤重击、5盾、5伤轻击；较高护甲让突刺、蓄势突刺及灼烧路线有明确用途。无灯执炬者（40 HP、护甲1）循环为蓄力预告、8伤重击、6盾、8伤守盾后重击、5伤轻击。蓄力本轮无动作并明确预告下轮攻击。护盾按契约保护下一玩家轮，之后在敌人下一行动前清零。突刺可绕过护甲但仍受玩家护盾规则约束；普通攻击每个伤害包先扣护甲再扣盾和生命。

轮数目标是预算而非测试结论：普通敌预期约2–4轮，精英约3–6轮，Boss约4–6轮；初始抽4张、每轮2能量、最多主动打2张会限制爆发。战斗受伤压力也受抽牌顺序、起始遗物选择和奖励牌加入影响。12轮失灯是超时压力，不应被视为正常击杀目标。

## 风险预算与待复核项

数值刻意保持在中等尺度：基础直接伤害4–9；奖励直接伤害5–10，另有重斩14（升级17）作为2费重击；护盾4–8；单次新增灼烧2–6；治疗4–5且消耗。升级通常增加2点，重斩增加3点，抢攻同时降低1点自伤。牌组只有8实体，抽牌波动较大；最多两张主动牌、每轮两能量带来1费铺牌与2费重击的取舍，但抽不到防牌时敌意图有实伤风险。起始徽章加伤、炽芯放大重复灼烧、精英护甲和Boss盾循环是偏强端；包扎消耗、Boss的高生命以及抢攻自伤是偏弱端。

主简化演算需重点检查：所有起始遗物的最佳选择是否过于显著；带灼烧奖励与炽芯时余烬骑士/Boss是否过早融化；无防牌手牌对8伤攻击的生命压力；Boss护盾循环与4–6轮目标是否冲突；随机抽牌下普通战是否常超4轮。参考模型覆盖了有限种子与固定策略，详见复核报告；真实玩家与后续章节仍未验证，也未定余烬金额、分数公式或第二幕内容。

## 首轮演算后的校准

余烬爆发原1费灼烧6在模型中表现偏强，现改2费，升级仍2费灼烧8；保留本战消耗与可回声，让高持续收益占满本轮能量而非顺便叠加一张攻击。纯灼烧是状态牌，不触发首次攻击增伤/火绒。费用调整前后使用同一批种子对照；完整结果以最终目录与复核报告为准。
