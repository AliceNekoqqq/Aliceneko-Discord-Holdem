# P3 首领阶段机制审计

## 范围与方法

对冻结的 v0.14 与 v0.15 分别运行 32 局全程存档：8 个职业 × 难度 0/6 × 2 个配对种子，共 64 局。固定种子为 `p3-{professionId}-d{difficulty}-s{1,2}`；路线沿用 P3 前两批审计的安全贪心选择，商店离开，战斗沿用合法两步贪心策略。每步 JSON 往返存档；同职业、难度、种子的两版路线完全相同（32/32）。v14/v15 的卡牌、商店和目标 Boss 以外目录均做了静态等价断言；允许差异仅为三名目标 Boss 的机制内容，以及六名 Boss 蓄力意图的 `next` 预告元数据。

每场战斗记录了实际敌人、战斗结局、阶段转换和战斗日志中的破势；节奏检验按结束本轮时真实出牌数核对护盾或攻击，半血预告按 `phaseNextIntent` 与下一轮实际意图核对。另有一场固定进阶牌组专项：v15 镜巷执政官，难度 10、10 张未升级斩击、无遗物、固定种子 `p3-boss-phase-fixed-deck-d10`。它在敌方 95 HP 中降至 59 HP 时越过 65% 阈值，核实转阶段后首个实际意图为「节奏检验」；该牌组只用于补充单场机制证据，不代表真人构筑或全程表现。

## 限制

这是有限、确定性的程序策略样本，不是玩家测试。贪心策略、固定路线偏好、商店离开和仅两个配对种子不能代表真人选择、职业平衡、策略多样性、手机呈现或趣味。胜率相同仅描述这 64 局，不证明 Boss 难度或体验保持不变。需要结合真人对战反馈再评估阶段节奏与可读性。

可复跑脚本：`scripts/audit-lantern-p3-bosses.mjs`。全量 JSON 输出包含每局路线与遭遇记录；审计报告只摘录汇总，不附 transcript 或静态资源载荷。
