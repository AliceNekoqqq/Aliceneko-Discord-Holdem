# beta.88 / 灯下迷城 v0.19

本版修复辅助牌可用性与获取节奏；保持124张牌、每职业6张专属、三幕路线及当前敌人参数。v0.18及更早存档继续派发原引擎、目录与获取算法。

## 行为

- 战斗奖励三个不重复候选：仍未持有且已解锁的职业专属、当幕通用发现、已有牌组补强。无专属缺口时回退；通用发现优先未持有牌，不强制玩家选牌。
- 商店对应展示职业发现、当幕通用、构筑补强，费用、购买限制及幕次门槛保持。
- 缝合拆盾按实际缺血量消耗偶数护盾，每2盾治疗1；保留不足2点的护盾和过量护盾。基础至多4盾治疗2，升级至多6盾治疗3，仍有能量/行动/护盾成本并本战消耗。
- 封口回收识别直接护盾、暂存盾、分流治疗的护盾模式，以及灼烧/伙伴/锻值/自身净化换盾。回收真实弃牌实体，不复制、不回收消耗堆、不回收本牌。
- 私密手牌文字显示抽牌预计数量、最近可回收目标、拆盾治疗实际消耗；抽牌预期计算打出本牌后的空位与可抽牌数量，条件抽牌按当前资源判断。手牌上限5、每轮通常3行动、额外行动上限4保持。
- 缺少启动牌的资源兑换牌不再标为明确补强。提示先补召唤、锻造、灼烧、护盾或回声蓄能。旧版评分算法保持。
- 借火冲刺的目录正反面说明补齐自损2点；界面原本已显示风险。
- 升级预览改用版本路由目录，能正确预览beta.87新增牌和本版拆盾治疗。每日挑战榜种子与v18隔离。
