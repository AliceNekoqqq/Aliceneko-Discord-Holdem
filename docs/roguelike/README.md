## 本阶段的关键结论

- 主线路已纸算：初始30→普通战后27→篝火30→Boss后23；拿到第一件遗物后可以继续或撤离。
- 每站只走一条支路；奖励处理后才推进，买完仍可留在商店，离开才完成本站。
- 第一/二幕Boss给遗物，最终Boss直接通关；攻击击杀后不再执行敌人的未到行动。
- 12轮战斗上限、72小时无有效操作关闭、旧按钮/重复请求、终局待结算与新局隔离已有规则；这些仅为设计，未实现。
- 150总日限额已经包含到店礼/伙伴/多人游戏；肉鸽金额、子上限、排行榜评分等待经济阶段校准。
