# 灯下迷城 · 地图与战斗实时画面

入口仍为酒馆大厅 → 小游戏 → 灯下迷城。远征面板附带当前幕的节点地图；进入战斗自动切换双方状态与手牌画面。选路、出牌、用道具、结束回合和领取战利品后，更新当前私密面板。战斗中的「迷城地图」为只读入口，「返回远征」恢复战斗画面。

地图从已保存的 mapPlan 与 path 绘制，使用服务端当前房间提供的可选项；走过、当前位置、当前可选、未来路线区分显示。旧存档缺少完整地图时仅显示已有的可见路线，不重新生成节点。战斗从已保存的 battle 读取生命、护盾、护甲、灼烧、能量、意图、阶段、伙伴/锻值及实体手牌；按存档版本选择对应目录与可用牌规则。

不改v0.8玩法、难度、经济、结算和存档。程序绘图复用现有Canvas、中文字体与PNG编码，不加入生图资源、公共局状态链接或轮询定时器。

rogue-interactions 的可选 onVisual 回调只捕获本次合法响应对应的状态。rogue-presentation 在原服务器DO里执行已提交动作后的绘图，并返回multipart；Worker把附件和文字/按钮一起PATCH到原私密webhook。切换普通详情或错误响应清除旧附件，绘图失败回退文字面板，不重复执行动作。Discord图片刷新和客户端手感仍需真人验收。

检查范围：地图所选路径与有效候选、旧存档目录、战斗阶段/费用/意图、PNG有效性/尺寸/确定性/不改存档、私密multipart替换、只读刷新、图像失败后不重复执行、身份校验、HTTP失败报告，以及现有肉鸽UI/交互回归。
