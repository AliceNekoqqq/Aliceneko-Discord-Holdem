# 灯下迷城 v0.9 重设计与复审

## 改动边界

新局启用 lantern-rules-v0.9；v0.4/v0.6/v0.7/v0.8 运行时和目录冻结，原存档按原版本继续。未重置玩家职业进度、钱包或每日奖励记录。继续使用原进阶敌人数值，不通过提高怪物属性制造路线取舍。

## 按顺序实施

1. 信使封蜡：每轮首次成功主动抽牌、择弃或保留获得备势1；自动轮首抽牌、回声和道具不触发，JSON 恢复保留已触发状态。
2. 医师徽章由营地治疗加成改为每轮首次主动实际治疗后的护盾2，帮助治疗在敌人行动前兑现防御；满血、回声、道具不触发。下位牌与重复牌：所有战斗精确重复组重新分工，同时重新检查升级后的重复与功能下位。
3. 灼烧：升级最多额外1层；炽芯、棱镜余焰、余烬钟舌各自每轮首次主动施加灼烧加成一次，三张火牌不会把三件遗物重复触发三遍。
4. 路线：每幕仅一处营地，在第2/3/4站随种子轮换；固定首站保留普通战，末站保留精英，以保证满足首领前至少一战。全图仍可提前查看，选择营地意味着放弃同站战斗/商店/事件机会。
5. 奖励池：第一幕34张、第二幕32张、第三幕24张独有新牌；随幕累计解锁。每职业前2张特色牌首幕可掉落、后2张第二幕解锁。奖励3候选不重复，至少1张来自当前幕的新池。普通共享起手牌与旧伤不掉落；旧版非掉落牌抢攻仍不进入奖励池。

## 验证与局限

- 全96张牌的基础/强化效果执行检查，无非法效果或非有限状态；精确战斗签名重复0。
- 奖励池跨幕重复0、错幕0；每幕有足够候选并保证当前幕新牌进入候选。
- 单营地种子轮换、路线可达性、旧版恢复、信使主动触发、0费牌三次出牌上限、灼烧遗物每轮限次、奖励UI与新目录均有回归检查。
- 模拟使用固定种子、两步贪心战斗、默认奖励；保守路线偏普通战和休整，风险路线血量至少20时优先精英/危险。模拟会放弃商店、少用有代价事件，也不会充分规划保留/回声；不代表玩家胜率或最优策略。
- 路线与卡牌重复度已降低；实际是否耐玩仍需真人多局反馈。高进阶需要更主动的组牌、商店、道具和首领交易，不能把保守模拟零通关直接判定为职业不可玩。
