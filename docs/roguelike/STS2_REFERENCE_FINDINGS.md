# 《杀戮尖塔2》机制参考：资源与成长节奏

**范围与口径（2026-10-10，Asia/Shanghai）**：本札记只覆盖基础能量/手牌/打击防御，以及休息、升级、卡牌与遗物奖励。指定灰机 Wiki 首页和相关页面的网页直读返回403；以下Wiki事实来自搜索引擎可见的页面索引摘要，不能视为通读全站。首页索引标明正式版v0.107.1、测试版v0.111.0；Wiki注明默认以正式版为准，⚠标记表示未加入正式版。以下机制按正式版页面摘要整理，测试版的内容只用于识别版本边界，不拿它覆盖正式版。Mega Crit官方确认游戏于2026-03-05进入Steam抢先体验，内容仍会新增和平衡，因此这里是当日可查基线而非永久定值。

## 已核实机制

- **每回合资源**：Wiki能量页索引称所有角色初始能量上限为3，回合开始补满；入门页索引称玩家回合开始抽5张，回合结束时除保留/虚无牌外手牌弃掉。基础循环是“每回合有限能量 + 新5张手牌”，玩家要在手牌内分配攻击、防守和功能牌。能量可能由牌、药水、遗物等额外改变。
- **基础牌有角色差异**：卡牌数据索引列出的铁甲战士《打击》为1费6伤、《防御》为1费5格挡；升级后分别9伤、8格挡。不能把它误写成所有角色共用的全局标准，更不能混淆《杀戮尖塔1》数据。此次只核到铁甲战士这一组示例。
- **休息点是路线取舍**：默认二选一：休息回复最大生命值30%，或锻造升级牌组一张牌。升级通常永久强化该局卡牌；卡牌页摘要也确认绝大多数牌可在休息处锻造。它把即时续命与后续战力放在同一个稀缺节点选择中。
- **卡牌奖励有稳定重复频率**：普通敌人胜利后给金币和一组卡牌奖励，可能给药水；入门页称每次奖励从若干组三选一中选取加入牌组。Wiki稀有度页摘要称每场战斗后奖励3张候选牌（特定奖励/机制可变）。因此“战后频繁小幅扩牌”是核心成长来源，跳过选择也应是合法决策（本次摘要未核实跳过规则细节）。
- **遗物按高风险节点集中发放**：Wiki房间页称精英战给卡牌奖励、更多金币、更高药水概率并额外给遗物；遗物页概述多个遗物来源；章节主线遗物奖励以当前先古之民规则为准，不据概述认定所有Boss都直接掉遗物。普通战斗与精英战的奖励密度不同，遗物构成改变整局打法的长线成长层。
- **阶段衔接也影响奖励节奏**：Wiki荣耀页摘要特别指出，击败阶段Boss后并非沿用前作的Boss遗物箱奖励，而是在新阶段遇见先古之民。不要把《杀戮尖塔1》的每幕Boss遗物流程当成2代现行主线。

## 对《灯下迷城》的取舍

旧方案为三幕9站、抽3选1、30HP、斩击6/盾8、单角色且不依赖模型。可以借鉴每回合“能量约束手牌选择”、战后常规卡牌成长、休息点二选一、精英风险换遗物这四层节奏；不建议照抄上述卡牌面值。尤其《灯下迷城》的盾牌8高于已查到的StS2铁甲战士初始防御5，斩击6则与其打击6相同，但脱离总回合资源、敌方伤害/意图、战斗长度、抽牌数、血量上限、9站内奖励次数与升级次数比较，单卡数值没有可比性。

应先固定一整局的资源预算再平衡：每场战斗每回合给多少能量、抽几张、敌方每回合威胁多少；9站会产生几次卡牌奖励、几次休息/升级、几次遗物奖励；玩家初始牌组与奖励扩牌后，牌组多久循环一次、是否常出现“有牌无能量”或“有能量无有效手牌”。以总伤害/总格挡/每轮可打牌数和可回复HP检验，再调斩击与盾牌面值。Discord交互应把一站的选择和战斗回合压缩成少量明确按钮；成长节奏可保留“战后常见小成长、稀有高风险节点大成长”，但9站短局无需复制长爬塔的奖励密度。
