# 灯下迷城 · 敌人、遗物与道具扩展附案

2026-10-10。Luna初稿经主agent整合。供设计评审，非已实现内容，**所有新增数值均未验算**。正式约束引用 [总规划](CONTENT_EXPANSION_PLAN_V05.md)，特别是抽4/2能量/主动2张/12轮/单敌、回声与道具触发限制。

## 1. 敌人是构筑的考题

候选18个新敌人，并非现有12个之外全部必做。首批选6个使目录达到18，长期再选6个使目录达到24；其余保留。不同章节遇敌按对应强度重标，不能只把第一幕数值加倍。所有攻击都有意图预告；单敌外观可表现多人影子，但不增加可点选目标。

| 候选 | 类型/建议章节 | 核心考题 | 至少两种应对 |
|---|---|---|---|
| 灯蛾窃火 | 普通/旧街 | 轻击后蓄势，第三轮重击 | 蓄势轮集火；当轮盾防重击 |
| 灰巷收债人 | 普通/旧街 | 小盾与攻击交替，穿甲不绕盾 | 撤盾窗口输出；施烧绕盾 |
| 镜面拾荒者 | 普通/镜巷 | 开场架盾，盾轮后低伤 | 空档铺预备；盾烧推进 |
| 雨棚鸦 | 普通/镜巷 | 两段低伤后单段高伤 | 大盾挡双段；反击利用多段 |
| 空瓶侍者 | 普通/旧街 | 轻微攻击反伤，仅一轮、限次 | 当轮防守/施烧；下轮直伤 |
| 巡灯学徒 | 普通/钟楼 | 蓄势窗口长，随后高伤 | 回声安排到攻击前；预备/追猎抢杀 |
| 裂甲巡官 | 精英/旧街 | 护甲与少量盾交替 | 穿甲打护甲；烧层打盾阶段 |
| 余烬看守 | 精英/旧街 | 每三轮有限削减烧层，随后空档 | 直伤再补烧；强施烧留到空档 |
| 镜链斗士 | 精英/镜巷 | 多段攻击后短暂高盾 | 反击截断后续段；烧层/预备渡过盾轮 |
| 失准校钟师 | 精英/钟楼 | 蓄力重击与轻击交替，不随机跳招 | 防重击；轻击轮重斩/标记 |
| 渡口税吏 | 精英/镜巷 | 护甲＋低频攻击，考验12轮进度 | 穿甲＋重击；持续施烧配防守 |
| 倒影猎手 | 精英/镜巷 | 每轮一次有限反伤，明确预告 | 一张强击＋防守；施烧跨轮推进 |
| 熄灯夫人 | Boss/旧街 | 重击→空档→短反伤窗口 | 空档标记/预备；灼烧防守 |
| 镜巷双面官 | Boss/镜巷 | 单敌高盾与多段阶段交替 | 烧层打盾；反击挡多段 |
| 钟腹巨像 | Boss/钟楼 | 护甲、沉重蓄力、有限架盾 | 预备穿甲；灼烧＋精确防守 |
| 渡鸦药师 | Boss/镜巷 | 低血只治疗一次，随后不治疗 | 追猎爆发越过窗口；持续伤害 |
| 无名引路人 | Boss/旧街 | 首张牌类别影响下轮意图，选择前预告分支 | 先盾诱导轻意图；先攻换高压抢杀 |
| 末班摆渡者 | Boss/钟楼 | 明示三轮循环，末段高伤 | 提前排回声；盾烧/蓄势按循环兑现 |

首批优先灯蛾、收债人、雨棚鸦、裂甲巡官、失准校钟师、钟腹巨像，先利用已有攻击/架盾/护甲/蓄势/多段。反伤、有限净化、治疗、条件意图与阶段变化需新规则及存档，不靠label文字冒充机制。

不让敌人永久免疫流派。削层有限且预告，反伤不自我连锁；不强制丢全部关键牌、不禁回声、不靠隐藏计时猝死。每个Boss提供至少一个铺垫窗口，在12轮预算内标定治疗/盾量。

## 2. 十件连接遗物候选

加总案中的留声蜡封、备用发条共12新遗物。牌自身已有基础连接，遗物强化它；没有关键稀有遗物也应可玩。以下数值待验证。

| 遗物 | 原型效果 | 连接与边界 |
|---|---|---|
| 熏灯罩 | 每轮首次敌攻击被盾吸收后，敌灼烧1 | 防守→灼烧；多段也一次，不触发主动施烧加层 |
| 裂纹镜片 | 每战首次回声执行后获3盾 | 回声→防守；战斗已终止不再给盾 |
| 苦药塞 | 每轮首次付卡牌生命代价且存活后获2盾 | 自伤→防守；不抵消已支付自伤、不回生命 |
| 封口药匣 | 每战首次主动消耗牌获3盾 | 消耗→防守；被其他牌消耗不算主动 |
| 猎火针 | 每轮首次对灼烧敌施标记时，标记至少3 | 灼烧→追猎；最高4/取较大/一次兑现 |
| 沉钟支架 | 每轮首次获预备时，若已有盾再获2盾 | 防守→预备；不加预备、不递归触发 |
| 鸦羽书签 | 每战首次消耗其他手牌时获预备2 | 筛牌消耗→预备；不抽牌、不还主动次数 |
| 焦黑封蜡 | 每战首次合格回声牌施烧时额外烧1 | 回声→灼烧；专用有限事件，不视为主动 |
| 割线剪 | 每战首次主动消耗攻击牌首伤包穿甲 | 消耗→破甲；不绕盾，回声不触发 |
| 门槛刻度 | 每战首次护盾牌施标记时额外获3盾 | 防守→追猎；必须本次牌确实施标 |

独立反击/伤害来源不能递归触发同类遗物。多反击、烧层、标记/预备叠加须单独校准；有限次数只防循环，不证明强度平衡。

## 3. 六种消耗品

局内2槽，**整场战斗最多主动使用一个道具**，每个实体使用后消耗，不是每种各一次。道具不占两张主动卡，但不触发出牌/回声/标记兑现/自伤/消耗遗物链。服务端操作版本与存档去重同卡牌。

| 道具 | 草案效果 | 取舍 |
|---|---|---|
| 止血布 | 恢复4生命 | 活过高压轮；满血禁用，不无限掉落 |
| 碎镜片 | 直接伤害5，经过护甲/盾 | 抢杀或被盾浪费，不兑现预备/标记 |
| 冷灰包 | 灼烧3 | 防守构筑收尾，仍先等敌行动 |
| 折叠盾 | 临时盾6 | 留给重击，回合末清零 |
| 鸦眼滴剂 | 本轮下张主动直伤牌首伤包+3 | 独立一次性来源，不触发预备获取遗物 |
| 退火盐 | 移除自身至多3烧层 | 真实玩家烧层来源实现后才入池 |

余烬购买/事件/固定奖励另做供给表。没有道具也需有完成路线。普通与同题挑战冻结各自供给，酒馆币不买竞技战力，不带回钱包兑换。

## 4. 引擎依赖

- 当前可表达：单敌HP/护甲、攻击/多段/蓄势/架盾、玩家伤害/盾/烧/治疗、自伤、实体消耗、既定遗物与回声。
- 待开发：敌方条件/阶段/治疗/净化/反伤，预备/标记/保留/换牌，新遗物触发，道具动作/供给/状态/UI。不能只补JSON。
- 事件区分主动牌、回声、敌攻击、反击、道具、自伤代价与实体消耗，保存来源和次数，旧按钮不再执行。
- 本轮不新增线上敌人与道具，不动旧局与钱包，不引用旧50项测试当新机制验收。
