# 灯下迷城 v0.7 / beta.54

本版扩充已进入正式引擎、私密面板、存档、结算与排行榜。8职业共用牌池，职业仅决定起手；驯兽师及铸器匠可跨职业混搭。目录共96张牌（95张构筑牌及1张高进阶旧伤）、31件遗物、30种敌人、10种道具、12种事件。

## 职业和战斗

每职业4通用牌加4特色牌，保留特色起手遗物。每轮5张手牌、3能量、最多主动打3张，12轮上限；回声每战最多3次、不递归、不复制治疗。道具2槽、每战最多用1件，不占主动次数；新道具包括抽牌、召唤、灼烧和备势。备势/标记/召唤/铸器/护盾/灼烧/回声/消耗等在共享奖励池连接，奖励提供已有方向、连接方向与公共牌三候选。

Boss与精英获得第二阶段。生命降到50%（进阶10为65%）触发一次，获得阶段盾；当前回合意图保持，下轮公开新意图。击杀不会被阶段机制救回。

## 地图和事件

三幕各5站：4次三分支选择与1次Boss。地图全局生成后存档，可分页查看；已走路径记录节点、敌人与事件。营地最多2次/幕；若此前完全避战，第4站只开放精英并显示锁定原因，保证Boss前至少一战。危险普通战生命+10%、攻击每段+1，胜利额外4余烬及一次遗物奖励。事件选项涵盖治疗、购牌、生命交易、道具、升级、删牌、余烬，可免费离开；花费或换槽先确认，动作验证当前房间候选与实体UID。

## 进阶与公平

每职业独立0～10阶，通关当前最高等级解锁下一阶；练习或0币结算仍可解锁，重复回执不再增加次数。旧版本已确认通关继承该职业进阶1。进阶与钱包/流水/结算回执原子提交，失败回滚后可重试。每日挑战职业与0～3难度由服务端按服务器、日期和规则版本固定，种子/榜单包含难度，客户端不能改题；高于当前解锁等级的挑战不会跳过解锁阶梯。
