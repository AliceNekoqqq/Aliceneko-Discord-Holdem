# v0.17 灼烧、战斗压力与营地补给

玩家反馈：灼烧配遗物过强，整体难度偏低，战斗回血容易使营地价值不足，并要求移除战斗回合上限。

## 调整

- 炽芯、棱镜余焰、余烬钟舌、守灯余火、余烬小铲：每次增加1层灼烧，每轮最多触发一次，每件每战最多触发3次。原先已有每轮一次；本次解决长期重复与多件叠加的累计收益。保留不同遗物叠加，三次预算各自独立。
- 战斗面板显示剩余次数；触发计数保存到战斗存档，跨轮和重开面板不会重置，下场战斗重新初始化。主动施火和实际挡伤触发沿用既有条件。
- 13张治疗牌的基础与升级治疗各减少1点，最低1点。全部仍每战消耗；野外包扎和止血药盾保留原值，避免医师因全局削弱丢失职业优势。道具与营地不受这次牌面减值影响。
- 各难度在原系数上增加8%敌人生命与每段攻击1点。原高阶机制、公开意图、破势和阶段预告继续工作。
- 营地仍回复9点，高阶4起7点；原营地遗物和契约惩罚继续应用。连续作战的缺血让营地回复与升级成为真实取舍。
- v0.17没有战斗回合上限。没有可用牌时，一次动作至多自动跳过一轮，再交还操作，避免空牌组在同步循环中卡住。没有另设回合数失败或隐藏限时。
- 新开局v0.17，旧v0.16及更早规则冻结；回声按钮/分页/升级与每日挑战分组继续兼容。聊天知识同步说明新旧规则。

## 验证

- 灯下迷城51个测试文件、聊天6个文件、Worker4个文件通过。
- 新增覆盖遗物每轮一次/每战三次、三件叠加、JSON恢复、多段攻击挡伤计数、21轮仍未强制失败、旧局12轮失败保留、空牌组交还操作、治疗消耗与营地回复、版本分流、每日分组与指南、私密回声交互。
- Luna独立模拟：同种子8职业×4种子，难度0，真实路线上全程合法动作，两步贪心策略，无注入生命。v16通关30/32，v17通关29/32；平均结束生命22.5→16.91，营地回血3次/25HP→15次/132HP，两个版本均无超时。医师原4/4、新2/4，是后续观察重点；其两张招牌治疗牌已恢复原值。
- 模拟保留奖励/房间/营地操作，但策略及四个种子不能证明真人胜率或玩法趣味。脚本`node scripts/audit-lantern-v17.mjs`复现v17，增加`--v16`复现旧规则；结果摘要见V17_BALANCE_SIM.json。没有用模拟通关率宣称真人平衡已验收。
