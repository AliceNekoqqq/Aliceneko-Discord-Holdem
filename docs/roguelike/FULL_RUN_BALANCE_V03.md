# 三幕资源与节奏复核 v0.3

2026-10-10。本轮完成的是内容设计与参考模型，不是Bot服务。保留第一幕v0.2数值，补齐第二/三幕，并逐段执行多段攻击；全局20种牌、12件遗物、12种敌人、9完成站。

## 可复现方法

在本目录运行 `python full_run_sim.py`。仅使用Python标准库，程序从RUN_CATALOG_V03.json加载内容、复用reference_sim.py战斗。24种子×3起始遗物×3战斗策略×3路线，共648条整局；另存seed7的安全/冒险两条逐轮样例。固定策略只看当前回合，非最优搜索、非人类胜率。奖励按声明的效果权重选，不跳过；均衡路线HP≥22打精英，否则休整，阈值不是玩家必胜攻略。

安全路线走篝火、第二幕商店和第三幕修灯；冒险路线每幕普通＋精英，余烬最多但无商店/修灯消费。商店模型只买至多1牌并在可付时删未升级突刺，不使用升级服务，不验证整个商店交互实现。事件可补6HP或买本幕牌，但模型不验证取消/重复请求。整局样本全部选择继续，不包含撤离局统计。

## 发现与处理

1. 安全路径能用少战斗换治疗/升级和精简牌组，但少拿精英遗物；不是只有硬打才到终章。模型已有多条安全通关，修灯12余烬、商店10/14及删牌8确有消费。seed7累计获得80、花30、剩50，不兑换真钱包。
2. 冒险路径有更多牌与遗物，净收入156余烬；全程不防守的偏进攻策略0/72通关，攻防均衡47/72。保留这一风险，不为凑总体通关率削弱所有敌人。正式UI应在第二幕精英及检查点直示HP/强度并允许休整或撤离；撤离金额仍待经济设计。
3. 偏防守有49次失灯，即使HP高也不保证胜利。12轮上限要求输出；模型失灯集中在后两幕，需要实机查看它是否让防守流派难以理解。先保留上限并清楚显示，未定最终难度。
4. 章节赐福和灼烧可叠加，灼烧绕甲盾；纯烧消耗牌、每轮2能量/最多2主动牌与20层上限限制爆发。本轮未独立穷举三件烧层遗物＋回声的极端组合，不能声称三流派等强。后续需针对强组合与真人选择复核，而不是再机械增加随机样本。
5. 终局剩余余烬不是成绩，消费也不计分。若以囤余烬/精英次数直接发币，会反过来惩罚补给并鼓励刷重复精英；经济阶段需按实际完成与风险、日限额一起定，当前不承诺通关30币或肉鸽60币子限额。
