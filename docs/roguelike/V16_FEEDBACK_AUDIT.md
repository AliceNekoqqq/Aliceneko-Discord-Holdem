# v0.16 玩家反馈修正

## 范围

玩家反馈攻弱守强、回声没有操作入口、组合触发不清楚。新规则冻结旧版本；新局切至v16，每日挑战使用独立分组。

## 数值

- 1费直伤3/4分别增加2点，5增加1点；6及以上保持。对应升级增加相同差值。
- 1费护盾6减少1、7/8减少2、9及以上减少3；升级保留原升级增益。铁门闭合9/11改为6/8，灰墙8/10改为6/8。
- 全目录逐项核对：26个1费直伤效果、46个1费护盾效果；基础盾上限6。2费重击与敌人数值未改。多效果牌仍需真人组合观察。

## 回声与组合

- 回声蓄能后打出可回声牌，使用可见按钮选择真实UID，安排下轮免费重放，不计能量和出牌次数；治疗不能重放，自损照付，每战至多3次。
- 升级蓄能给两次选择，本牌回声升级安排两份；回声不递归。
- 最后一张可用牌/第三张牌打出后，若有可选回声则保留当前轮操作窗口；玩家安排回声后可点击结束回合。
- 选择器每页25张，全部UID可达；按钮/选择均沿用私密、归属、版本与标准动作幂等流程。
- 备势/标记/锻造/伙伴/反击自动触发，战斗提示与玩法说明写明条件。

## 检查与限制

灯下迷城49个测试文件通过，Worker4个测试文件通过。新增覆盖低伤攻防、旧目录隔离、升级双回声、不递归、不耗行动、最后出牌窗口、私密选择动作、超过25张分页、版本与每日分组。Luna独立代码审查发现分页缺失，修正后补测。

本批让回声组合能够主动选择，并增加进攻/防守的取舍。模拟与自动测试不能证明游戏已足够丰富；实际操作可读性、各职业胜率和重玩兴趣仍待玩家反馈。
