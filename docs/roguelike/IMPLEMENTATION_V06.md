此文记录实际运行时。旧v0.5是设计草案；本版直接上线八职业及配套，不按旧案分批开放。

入口：`/灯下迷城`，或 `/酒馆 大厅` → 小游戏 → 灯下迷城。私密面板内选择普通职业或每日固定职业挑战，可练习、跨频道恢复、查看详情及榜单。

目录共62张牌、25件遗物、30种敌人、6种道具。每职业8实体起手+1特色遗物；卡牌共用奖励池，无职业锁。奖励三选一包含已有牌组相关、连接新标签、公共池三个方向；按章节开放，候选一次生成随存档保存。非起手遗物进入精英及章节池，其他职业的起手遗物也可通过精英奖励获得，已持有项排除。

可直接搭建的连接例子：炭墙连接火与盾；灰烬记号连接火与标记；盾锋转刺连接盾与直接输出；余烬回声连接火与回声；狐火铆钉连接召唤、锻造与防守。单张桥梁牌也有基础效果，不要求集齐套装才能使用。职业适应性、牌池和敌人轮换提供每局不同选择，模拟结果不视为最终平衡或真人胜率。

## 战斗规则

- 每轮4手牌、2能量、最多主动2张；12轮限时。消耗/择弃/保留使用实际UID目标并占主动机会；保留仍占手牌容量。
- 备势最多6、标记最多4；叠加并留到下一轮结束，下一次主动/回声的首个直伤包一次兑现。道具和反击不消费这两种资源。
- 伙伴生命最多12；敌方每段攻击依次扣盾、伙伴、玩家生命。伙伴攻击需主动打牌，无自动免费攻击；生命代价及反伤直接伤害玩家。战斗开始重新初始化伙伴。
- 锻值最多12，战斗内跨轮保留，武器攻击加上锻值；新战斗从0开始。铸器匠与钟楼匠有不同起手机制。
- 回声每战最多安排2次，单次操作最多安排1次，下一轮按保存后的升级牌效果与生命代价结算，不创造新牌实体，不递归排回声，不重放治疗牌。
- 所有被动按明确主动/回声/道具/反击来源区分；按轮或按战限次；胜负立即截断后续段与触发。
- 敌人可多段攻击、护盾、临时护甲、烧伤、清火、反伤、首张主动牌类别条件分支；意图与分支提前可见。每幕固定抽取Boss，刷新与恢复不重抽。

## 道具、事件与存档

两个道具槽，每战总计可使用1件；0能量、不占主动次数。战利品、商店和事件真实投放。商店每件8余烬，满槽必须明确原子替换；用过后库存减少且跨战保存。

六件道具：止血布（治疗4）、碎镜针（穿甲直伤5，受盾阻挡）、冷灰包（烧3）、折叠盾（盾6）、磨刀油（本轮下一次主动首包+3）、退火盐（移除自身火至多3）。无效纯治疗或退火按钮禁用。

四种事件：修灯铺（付费治疗/牌）、借火人（付2生命换牌且须留1生命）、失物摊（免费牌/便宜道具）、夜行药铺（便宜治疗/道具）。选择与付款确认保留具体牌、道具和替换槽。免费离开始终可用。

既有SQL酒馆DO保存职业、牌堆、UID、伙伴、锻造、有限触发、回声、道具、候选、Boss计划、版本和随机流。v0.4存档仍由独立冻结模块解释；未知版本拒绝。新的正式局默认v0.6，每日职业与种子由服务器固定，客户端不能注入库存、时间或资格。

经济沿用累计0/8/18/30币；北京时间前2次有奖开局、每日远征60子上限并纳入酒馆150总上限；终局回执、钱包、流水、日桶原子，0币不次日补领。排行榜独立可重试，同题按最高分与并列排名，放弃/过期不入榜。
