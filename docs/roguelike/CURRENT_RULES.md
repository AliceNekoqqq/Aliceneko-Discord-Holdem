P0/P1第一批只增加本局观察与事实型构筑提示，不改变牌、敌人、掉落、回合或奖励数值，故不新增规则版本。观察只覆盖接入后成功动作，不能用缺失记录推断玩家没有操作；构筑提示不等于成熟流派或最优解。

改规则前先核对以上入口，再更新对应版本、索引、验收记录与PROJECT_NOW.md。真人体验尚须验证选择理由、卡手、理解、耗时及重玩意愿。

## P1 v0.10

八职业各提供两个机制方向，组件仅参考实际牌组，缺口不能视为成型证明。静钟时刻与清创切口前移至第一幕，分幕新牌池36/30/24；牌效与数值保持v0.9。实际治疗、溢出治疗、敌人攻击盾吸收、备势/标记投入、主动补抽、成功保留、强化牌主动使用及回声重放按可靠结算点累计；备势/标记投入不等于最终生命伤害。详情和结算展示摘要，战斗首页保持简洁。

旧版P0/P1第一批保持原规则。本批机械回归及边界测试见P1_V10_AUDIT.md；成熟打法与趣味仍待真人验证。
