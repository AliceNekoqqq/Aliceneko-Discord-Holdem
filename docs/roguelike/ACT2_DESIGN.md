# 第二幕：镜巷

镜巷将窄街、铺满银片的门脸和彼此映照的巷口连成迷宫。远处看似出口的亮处常是镜面；战斗里，敌人借折返路线连续出手。这里的压力来自连续小段伤害、护甲和架盾时机，玩家要在保留护盾、反击收益与尽快削减敌人之间取舍。

三张奖励牌各自提供一种路线：镜银护幕一费给少量护盾并施加灼烧，升级后两项都增强；与炭幕相比，它更偏灼烧、护盾较少，适合预判伤害较低时使用。镜针一费造成少量无视护甲伤害并附带护盾，升级后加强两项；它不与蓄势突刺争同一个纯伤害位置，而是让玩家以较低伤害换取小额防护。长明镜芒以两费、消耗换取较高灼烧，适合有空档时投入，若回声铃重放则仍按既有回声规则。每张牌都可升级，升级数值以JSON为准。

章节遗物提供三个不同取舍：棱镜余焰放大每次主动施加的灼烧；门镜扣强化每轮首次护盾牌；镜巡徽记提高首次主动攻击的首个伤害包。选项偏向灼烧、防守或集中直伤；遗物候选可跳过，不能和已有同ID遗物叠加。

镜翅蛾以双段攻击与短暂镜粉盾交替，少量护盾可能被连续两击耗尽；缝影客有一轮蓄势，交错攻击后回身补击，护甲迫使玩家考虑镜针或灼烧，而不是把所有伤害牌都当成同等有效。两者是普通路线的压力测试。

棱镜守卫先预告双段聚光，随后立盾，再用三段碎光；留盾可减少逐段漏伤，镜面护符若已持有，则每个被盾吸收的攻击段都可能反击一次。镜巷执政官交替两轮蓄势攻击与镜墙，并以三段碎镜和残影追击组成收尾。护盾应按段吸收，反击逐段判定；若反击击杀，剩余攻击段取消。精英与Boss都提供可读预告，但会检验玩家是否把护盾留到多段攻击，而非只看总伤害。

路线由主流程决定：普通战更适合保留生命、补充牌组；精英路线承担多段攻击风险，换取精英奖励机会。场景只到镜巷，不扩展新状态或敌人意图。所有牌值、护甲、生命和意图以 [`ACT2_CONTENT.json`](ACT2_CONTENT.json) 为准；它们是原型数值；已纳入648条三幕策略样本，结果见FULL_RUN_BALANCE_V03.md，不代表真人实测、上线或最终平衡。
