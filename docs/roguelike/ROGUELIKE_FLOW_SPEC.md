# 灯下迷城：流程与第一幕房间原型

状态：设计稿，供后续实现引用；不代表已接入或已平衡。规则基线 `lantern-core-v0.1`。本稿只覆盖游戏流程、房间交互和第一幕原型，不扩展城市、宠物或多角色。

## 阶段动作表

所有动作由局主在原服务器发起，携带runId与当前操作版本。成功动作原子保存资源、结果、阶段和新版本；重复提交返回既有结果，过期版本不执行。失败或存储未提交时不扣资源、不推进。打开面板、查看规则/详情、刷新、返回同一面板都不是游戏动作。

| 阶段 | 合法动作与前置 | 持久化结果与下一步 | 回退、重试 |
|---|---|---|---|
| HOME | 开始普通局/当日挑战：无进行中局；继续：本人本服存在进行中局；放弃须二次确认 | 新局固定种子、规则版本、归属服、初始牌组/生命、72小时计时，进入ROUTE；继续读取原阶段 | 开局提交失败可用同一请求重试；不能覆盖旧局。放弃终结为ABANDON、无奖励，不可恢复 |
| ROUTE | 仅选择已保存的两条支路之一；展示类型、风险和奖励方向 | 固化唯一选中房间，进入ROOM或BATTLE；记录另一支路不可达 | 刷新不重抽；确认后不可换路。按钮过期可重载当前路线 |
| ROOM | 按房型操作：休息二选一、购物、事件选项、开宝箱或离开；商店可连续购买 | 非商店房型处理后完成本站并进下一ROUTE；商店每次购买后仍留ROOM，只有离开才完成本站 | 资源不足/前置不符不改变状态；购买结果已写入则重试只回显。离店后不能回访 |
| BATTLE | 仅选当前已保存手牌中的一张；可查看意图 | 依核心规范逐项结算并保存牌堆、弃牌、生命、状态、敌人意图和轮数；普通/精英及前两幕Boss胜利进REWARD，最终Boss胜利直接CLEAR RESULT，死亡/失灯进RESULT | 不可重抽、换牌或重复打出；断线恢复同一回合。过期按钮拒绝并回显当前手牌 |
| REWARD | 选一项固定候选或明确跳过；奖励尚未处理时不可选路 | 记录一次选择/跳过及获得物；非终局战斗完成站点后进ROUTE；第一/二幕Boss后进CHECKPOINT；第三幕Boss胜利直进CLEAR RESULT | 可安全重试同一选项；不同选择的重复请求被拒绝。最终Boss不产生遗物候选或多余奖励房 |
| CHECKPOINT | 第一/二幕Boss胜后选择继续或确认撤离 | 继续清战斗临时状态并进下一幕ROUTE；撤离保存RETREAT及已完成节点，进RESULT | 选择后不可反悔；未确认保持本阶段，仍受72小时期限 |
| RESULT | 查看结果/结算状态；仅CLEAR/RETREAT/DEFEAT按经济接口结算；可开始新局或返回 | 先固定唯一终局和结算ID，再记待处理/到账金额；成功后只标记已到账 | 入账失败留在结算待重试，不重开战斗；同结算ID幂等。ABANDON/EXPIRED无币 |

72小时从开局起算；只有成功选路、选牌、购买、处理房间、处理奖励、继续章节、确认撤离/放弃等有效游戏动作刷新期限。打开界面、失败操作、无效旧按钮、刷新和结算查询不续期。任一有效动作到期前提交成功即按新时间保存；到期后先检查截止时间，拒绝新动作并原子终结为EXPIRED，无币、无撤离资格。超时检查不要求常驻轮询。玩家主动放弃必须二次确认，表示自愿结束且不可领撤离奖；撤离只出现在Boss后的CHECKPOINT，表示已击败该幕Boss并按撤离规则结算；到期是系统关闭，不等同死亡或玩家选择。三者均不能继续原局。

## 房间原型与通用规则

地图每幕前两站各有两条已生成支路，玩家每站只能走一条；第三站固定Boss。第一幕第1站的两条支路都是教学普通战，第2站为篝火/精英分岔，保证有非战斗选择；不要求第1站也有非战斗房。路线、房间内容、奖励候选、敌意图均在对应揭示时固定保存，不因刷新或恢复重抽。任何房间不能要求先付费才能离开。跨房保留生命、牌组、遗物、余烬；进新战前清除护盾、灼烧、回声等战斗临时状态。

| 原型 | 合法操作/条件 | 结果与退出 |
|---|---|---|
| 普通战斗 | 按保存手牌出牌至胜负；示例敌人12HP，每轮攻击3 | 胜后给固定三选候选：点燃（伤害3并施加3灼烧）、两张占位候选；选一或跳过才完成站点。候选不含隐性收费 |
| 精英 | 正常战斗，进入前显示风险与奖励方向 | 胜后进入REWARD；败/12轮失灯进DEFEAT。精英不保证可无伤通关 |
| 篝火 | 仅选治疗或删牌一次；治疗示例回复8且不超过30上限；删牌前确认目标且删后至少3张实体牌 | 选择立即生效并完成本站。牌组不足3张时删牌选项禁用；不能连续治疗或撤销 |
| 商店 | 展示已锁定商品、价格与余烬余额；逐件购买或离开 | 购买事务先验证余额及库存，再扣余烬/标售罄；成功后仍停留ROOM，允许购买其余未售商品。失败不扣款。买不起、全售罄或空手均可离开；只有离开才关闭房间，之后不可重进 |
| 事件 | 在确认前显示代价、可知后果与不可逆性；仅可选列出的选项或离开 | 选择一次后按固定结果保存；不得随机追加代价。首批不提供必选且会致死的生命代价 |
| 宝藏 | 开启一次并领取固定余烬、牌或遗物之一；如有代价须事先展示 | 内容/候选先固定，领取或明确放弃后完成本站；重试不能重复领取，不可开启第二次 |

第一幕完整战斗算例引用 [ROGUELIKE_FIRST_ACT_WALKTHROUGH.md](ROGUELIKE_FIRST_ACT_WALKTHROUGH.md)：教学普通战胜后旅人27HP，第二站选篝火回复至30HP；Boss三轮后玩家23HP并胜，Boss遗物三选一后进入CHECKPOINT，可继续或撤离。本稿不重复战斗数学；篝火/精英分岔只能选其一，精英奖励仍须确认或跳过后才能推进。

## Boss奖励与幕间流转

第一幕和第二幕Boss胜利后各进入一次固定遗物三选一REWARD；选一或明确跳过后进入CHECKPOINT，选择继续或确认撤离。第三幕最终Boss胜利直接固定CLEAR并进入RESULT，不生成额外遗物候选、遗物选择或后续房间。奖励处理前一律不能推进；REWARD重试不得重复取得奖励。

## 实现前检查点

存档至少保证runId/用户/服务器、规则版本、幕与站、已选路线、已完成节点、当前阶段与操作版本、生命/牌组实体、余烬/遗物、当前战斗手弃牌及意图、固定候选、最后有效动作时间、终局原因和结算ID可原子恢复。必须验证旧版本按钮不能替代新手牌、奖励处理前不能推进、重复购买/开箱/奖励不能重复生效、Boss终局不重开战斗。数值仅供流程演算，不承诺平衡、胜率或奖励经济结论。
