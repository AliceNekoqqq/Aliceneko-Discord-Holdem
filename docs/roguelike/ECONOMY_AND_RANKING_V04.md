# 灯下迷城 · 评分与终局收益 v0.4

2026-10-10，北京时间。已写成程序模块及SQLite服务；当前尚未接到线上Worker/大厅。内容目录沿用v0.3，收益规则为lantern-economy-v0.4，JS规则为lantern-rules-v0.4。

## 收益以一局终局计算

| 终局实际完成 | 基础酒馆币 | 说明 |
|---|---:|---|
| 第一幕Boss未完成 | 0 | 不靠重复普通战刷币 |
| 已完成第一幕 | 8 | 检查点撤离，或后续战斗死亡/失灯 |
| 已完成第二幕 | 18 | 检查点撤离，或第三幕死亡/失灯 |
| 三幕通关 | 30 | 总共30，不是8+18+30 |
| 主动放弃/72小时过期 | 0 | 已完成幕数不抵消明确放弃/过期规则 |

开局免费，不押酒馆币；局内余烬不兑换、不计最终奖励，买牌/治疗不会扣真钱包。币数与积分分开，高分没有额外币倍率，精英只提高构筑/积分机会，不是必须打精英才有通关30币。

同服每人每天最多2次有奖开局，普通冒险与每日挑战共享。名额在创建局时原子占用，失败/放弃/过期不退名额；开局前可主动选择练习保留名额。第3次及以后自动练习，可继续游玩；每日挑战练习仍可更新同题最佳分。正在进行一局时再次打开会恢复原局，不占新名额。RESULT不占活跃名额，旧结果独立保存。

肉鸽结算日子上限60，包含在现有酒馆币总上限150内，与20到店礼/伙伴20等竞争剩余额度，消费不恢复额度。实际到账=min(基础币,肉鸽剩余额度,总剩余额度)，最低0。练习/放弃/过期实际为0。0币也记录唯一runId回执，不能次日补领。

### 日期与延迟结算

开局名额使用服务端开局北京日；榜题属于开局日。**实际入账额度使用首次成功入账的北京日**，不能把今天收到的币回填昨天以绕开今天150/60上限。这确定了v0.3中尚未决定的日期策略：开局日管资格和榜题，结算日管收入。重试始终读第一次回执，不再次计算日期/限额/金额。客户端传入now不会控制时间，服务只用服务端clock。

同一guild绑定的酒馆SQLite内，终局动作/存档/请求凭据先一次事务固定，保留评分与基础币快照。入账另用同步事务更新余额、tavern_daily、rogue_daily、ledger、receipt与付款快照；该事务失败全部回滚，但不回滚已保存的通关。RESULT待结算不占活跃名额，可开新局；恢复/新局时按需重试本人最多3条旧结果。数据库提交成功但响应丢失，重复requestId返回现状，不重复收入。查榜/看详情/刷新不延长72小时期限。

## 每日挑战评分

积分 = 完成Boss数×1000 + 已完成站数×50 + 精英胜利数×40 + 存活终局HP。

HP仅CLEAR/RETREAT加入，范围0–30；死亡/失灯不加HP，放弃/过期不入榜。第一/二幕Boss后有撤离检查点；已选择支路但奖励未处理完的站不计完成。精英胜利是战斗已确认事实，不把尚未击杀的精英算入。通关最低3451分，高于任何未通关局的进度/精英/HP组合；后续成就奖励不修改此积分。

不计点击速度、现实时间、钱包余额、余烬、消费额或永久设施属性。通关与更深进度优先，精英提供最多120分的风险选择；治疗可改善存活HP但最高30分，不能无限刷。

同服/同开局北京日/同规则版本/同30HP、2能量、抽4和8起始实体牌组成一个榜题和种子组。初始遗物可自行选择，但所有人面对同一选择集；普通随机局不上每日榜。地图、奖励、商店/事件与每个战斗用独立稳定JS随机作用域，候选首次生成保存，重开/刷新不改同题。JS hash+xorshift与旧Python参考随机序列不同，旧seed7演算不声称是正式规则同种子的路径。

允许无限练习重试，每人只保留同题最高分；相同分数并列，展示顺序可按首次达成时刻稳定排列但不改变名次，使用竞争排名1、1、3。榜题公开而非秘密，不以藏种子阻止练习。

钱包与排名分别幂等：收入事务先写排名outbox，独立事务更新同题最佳分；排名失败不能回滚已到账的钱。看榜、新局/恢复/结算时按需重试最多20条待更新记录，不持续轮询，不另占已有DO alarm；排名待更新在私密结果页提示。

## 与酒馆经营衔接

现有4设备900/1500/2200/3600、总8200保持。仅肉鸽最多60币/收益日，新玩家欢迎金60且完全不消费时，900设备仍至少需要14个收益日；现有全部游戏日总上限150下，4设备累计仍至少55个收益日。这是收入上限的算术下界，不保证真人每天都赚满，也未含原有余额、到店消费、经营门槛或装修。

本版先让单人模式补足收入来源，避免一局解锁全部设备；不借肉鸽顺手改设备/装修价格，不新增付费数值或通关卡点。最终难度与收益体验仍需真实Discord试用，测试/模型不是真人经济观测。
