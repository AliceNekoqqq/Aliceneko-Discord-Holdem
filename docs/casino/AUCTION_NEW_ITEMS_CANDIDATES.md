## 接入说明（给执行者）

1. **不要直接改** `models` 里已生成的大图集或 Base64；新增藏品走源表 + 生成脚本。
2. 数据源：
   - 名称/品质/尺寸/类别/描述：`tavern-auction-data.mjs` 的 `AUCTION_ITEMS`，大件在 `tavern-auction-large.mjs` 的 `AUCTION_LARGE_ITEMS`
   - 价格：`assets/auction-art/prices-v1.json`
   - 权重：`assets/auction-art/drop-weights-v1.json`
   - 大件：`assets/auction-art/large-props-v1.json`
3. **必须把 `catalogVersion` 提到 8**（`tavern-auction.mjs` 开局处），旧局仍按各自版本池/价格结算，不得用新池覆盖。
4. 美术：256×256 真实透明 PNG → WebP，风格与现有 204 件一致（写实 3D 道具、旧货/收藏品质感差异）；同步更新 `assets/auction-art/README.md` 与哈希记录。
5. 概率：新增件必须重新计算图鉴公开的"同色占比/每件/每仓"概率，交由服务端容量感知模型，不能套独立抽取公式。
6. 大件规则：6/9/12 格、每仓最多 1 件、按区 15/25/40/55% 尝试镇仓位；新增大件不得超出各仓容量。
7. 测试：新增后需跑 `npm run test:tavern` 与 `npm run test:worker`，并核对图鉴计数、价格尾数、旧局兼容。
