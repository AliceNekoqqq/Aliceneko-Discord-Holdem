# NPC 出价激进度调参（2026-11-03）

用户反馈「NPC 出价太难赢」。本文记录测量方法与调整结果，便于后续继续微调。

## 结论

`npcAuctionBid` 的 style/轮次曲线**结构不变**，只增加一个全局系数：

```
NPC_BID_AGGRESSION = 0.85
factor = [0.78, 0.94, 1.08][style] * (0.64 + round * 0.06) * (0.90 + random(21)/100) * NPC_BID_AGGRESSION
```

调整后，NPC 的出价上限约为其自身估值的 **0.949 倍**（第五轮、最贪的 style、随机数拉满时），此前是 **1.117 倍**——也就是说原来对手会报出高于自己估值的价格。

## 测量方法

固定种子回放，V7 池（204 件、四区、容量感知大件），每个「区域 × 角色」跑 400 局（每区 1200 局、三角色共 3600 局），
对同一批棋盘比较不同策略，NPC 随机数消耗顺序与生产一致。
策略含义：按玩家可见估值（`session.estimate`）的 80% / 95% / 100% 出价；`max` 为永远报满预算。

## 胜率与盈利（按玩家估值 95% 出价，最接近正常玩法）

| 区域 | 调整前胜率 | 调整后胜率 | 调整前盈利率 | 调整后盈利率 |
|---|---:|---:|---:|---:|
| 小额 | 37.8% | **71.3%** | 2.4% | 9.3% |
| 常规 | 36.7% | **71.3%** | 5.4% | 15.2% |

按估值 80% 的低价策略：胜率 16.2% → 36.2%；按 100% 出价：47.7% → 77.9%。

## 需要如实说明的边界

- **本调整只提高「赢到」的概率，不保证赚钱。** 按估值 95% 出价时，常规与高额档的期望净收益仍偏负：这是赢家诅咒（赢下的往往是估值偏乐观的仓），属既有经济设计，不在本次调整范围。
- 典藏档基数大，调整后 ref95 的期望净收益已转正（约 +15.4 单位，1 单位 = 100,000 竞拍币）。
- 本调整对**进行中的旧局**同样生效：NPC 报价每轮按当时代码现算，不写进存档；已封存的当轮报价不会被改写。玩家侧无资产风险。
- 未改动：预算、入场费、汇率、价格、掉率、技能、`decideAuction` 提前成交倍率（2 / 1.6 / 1.3 / 1.1）。
- 本次**未提升游戏版本号**，`/health` 仍为 `casino.16`；如需版本标记可另行提升。
