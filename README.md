# Aliceneko 游戏 bot v1.0.1-beta.20

Discord 服务器内的虚拟筹码无限注德州扑克，运行于 Cloudflare Workers + SQLite Durable Objects。无需持续网关连接，使用斜杠指令、按钮和加注窗口。

## 玩法

- `/德州 创建`：当前频道创建一张牌桌，桌主自动入座。
- `/德州 测试`：创建电脑陪练桌，默认 2 位电脑，可选 1～8 位；一个人即可测试。
- 桌主可在私密「牌桌管理」中，在手牌结束时添加/移除电脑。电脑约 1.5 秒后自动行动，筹码归零后在下一手开始时免费补充。
- 电脑使用本地规则策略，只查看自身底牌和公共信息，不接入外部 AI API。
- `/德州 帮助`：查看玩法；`/德州 牌桌`：找回牌桌并刷新。
- 2～9 人；入桌 2000 筹码；盲注 10/20；行动 60 秒。
- 每手所有参与真人准备后 5 秒自动发牌；电脑自动准备。每手结算清空准备；取消准备或人员变化取消倒计时。桌主保留管理菜单内的手动发牌。
- 底牌以仅本人可见的响应展示。公开消息仅展示公共牌、行动、筹码和正常摊牌结果；弃牌玩家底牌不会公开。
- 过牌、跟注、弃牌、加注、全下；加注输入本轮总下注。
- 正确处理短全下加注权、多人边池、平局分池和余数筹码。
- 超时自动过牌或弃牌；连续两次超时将在本手结束后暂离，保留筹码，恢复参与后才会再发牌。牌局保存后可跨实例休眠继续。
- 归零后可免费补充。游玩中可预约本手结束后离桌，也可取消预约；下注、全下和当前结算不受影响。离桌清空本桌筹码，重新加入重新发放；无持久全服积分。
- 桌主或具有管理员/管理服务器权限的成员可关闭牌桌，未完成下注原数退回。
- 虚拟筹码仅供娱乐，无充值、提现或兑换。

## 部署配置

源码不包含任何真实 Token、邮箱、账号编号或服务器编号。Cloudflare 已部署的环境变量由控制台管理：

| 名称 | 类型 | 用途 |
|---|---|---|
| `DISCORD_APPLICATION_ID` | 文本 | Discord 应用 ID |
| `DISCORD_PUBLIC_KEY` | 文本 | Discord 签名验证公钥 |
| `BOT_TOKEN` | Secret（加密） | 注册斜杠指令、超时后更新牌桌 |

在 Cloudflare：Workers & Pages → discord-holdem → Settings → Variables and Secrets → Add，选择 Secret，名称填 `BOT_TOKEN`，值填写本人保管的 Bot Token，保存部署。不要上传到仓库或发到聊天。

每分钟的定时任务检查命令版本，Token 配置正确后自动注册 `/德州`；首次启用定时任务可能有传播延迟。成功注册后不再重复注册同一版本。不会覆盖应用的其他命令。

Discord 开发者后台的 Interactions Endpoint URL 使用实际 Worker 地址的 `/interactions` 路径。

服务器安装需 `bot` 和 `applications.commands`，频道权限为查看频道、发送消息、嵌入链接。无需管理员权限，也无需读取普通聊天内容的特权 Intent。机器人的频道权限应覆盖玩牌的频道。

## 隐私措施与边界

- Ed25519 验证原始请求体和时间戳，拒绝无效签名及超过五分钟的时间戳。
- 玩家身份来自 Discord 已签名的 interaction；不接受客户端指定要查看的其他玩家 ID。
- Durable Object 仅由 Worker 内部调用，无公开状态、底牌、数据库或源码路由。
- Bot Token 仅使用加密变量。为自动更新私密手牌，interaction token 使用 AES-GCM 加密后单独保存，最长 14 分钟；到期、离桌或关桌后删除。明文凭据不写入牌局状态、仓库、响应或日志。
- 关闭应用日志、Logpush 与日志转发。错误响应不输出堆栈或环境变量。
- 公开健康检查仅返回 `{"ok":true}`；未知路径 404；响应 no-store、no-referrer、noindex。
- Durable Objects 保存 Discord 用户 ID、频道 ID、牌桌状态和手牌，以实现权限与恢复。Cloudflare、Discord 的平台管理和基础设施行为不由应用控制。
- 群友会看到服务器中原本公开的 Discord 用户身份和 Aliceneko 品牌；本项目不提供匿名身份或阻止从外部公开信息建立关联的保证。

## beta.7 空闲关桌与桌主接管

| 阶段 | 自动关闭条件 |
|---|---|
| 尚未发牌 | 5 分钟没有有效真人操作 |
| 本手已结算 | 从结算时间与最后有效操作中较晚的时间起，空闲 10 分钟 |
| 正在游玩 | 10 分钟没有有效真人操作，且本手仍可行动的真人均在最后有效操作后超时；取消本手、原数退回下注 |
| 没有真人入座 | 立即关闭，电脑不能单独维持牌桌 |

- 成功入桌、离桌、发牌、下注、补充筹码、调整电脑和接管桌主会重置空闲计时；看手牌、刷新、帮助、无效点击、电脑行动和自动过牌/弃牌均不会。
- 全下或弃牌的玩家无需继续行动，不纳入游玩中超时资格判断；正在正常操作的牌桌无总时长限制。
- 关闭前 1 分钟更新原公开牌桌，显示倒计时；正常操作会撤去提醒并重置计时。游玩中的提醒明确说明需要满足真人超时条件。
- 等待发牌或结算期间，桌主 2 分钟未交互且有其他真人入座时显示「接管桌主」；点击时重新验证入座身份、阶段、桌主活动和牌局版本。进行中的手牌不允许接管。桌主查看手牌或刷新会重置桌主在场时间，但不延长整桌空闲期限。
- 关桌持久化状态后移除公开按钮、显示原因并清理私密手牌；旧按钮不能复活牌桌，频道可立即重新创建。即使后台 alarm 延迟，也会在交互到达时先检查是否已到关闭期限。
- 旧版已存在的牌桌点一次「刷新牌桌」或使用 `/德州 牌桌` 即可启用清理计时；已过期的等待桌会立即关闭。旧版没有结算时间的牌桌首次迁移时获得一次 10 分钟结算等待期。
